# SceneTrip iOS App Store 제출 자료 (MZ2AZ-416)

작성 기준: 2026-10-16, 로컬 소스 `e822d6c`와 2026-10-15 시행 개인정보처리방침.
현재 작업 브랜치는 로컬 `origin/main`과 동일한 커밋에서 시작했다. 원격 최신 상태는 조회하지 않았다.
이 문서는 입력 초안이다. 네트워크 조회·빌드·기기 실행·App Store Connect 입력·업로드는 수행하지 않았다.
출시 무료 프로모션은 운영 전제이며, 가격 설정은 담당자가 별도로 한다. 아래 공개 문구에는 가격을 넣지 않는다.

## 2. App Privacy — 개인정보 표시 입력 초안

아래는 앱·서버·제3자 SDK를 합친 선언 초안이다. 선택 기능도 허용한 사용자의 데이터를 수집하면 포함한다.
`연결 예`는 실명뿐 아니라 계정·기기·앱 인스턴스 식별자와 연결되는 경우도 포함한다.
`추적 예 (조건부)`는 Meta 설정 활성화 + 시스템 ATT 허용 + 이용 통계 ON인 경우다.
ATT를 거부하는 사용자만 기준으로 앱 전체의 추적을 `아니요`로 선언하지 않는다.
수집하지 않는 항목의 연결·추적은 `아니요 (해당 없음)`로 표기한다.

목적 약어: **기능** = App Functionality, **분석** = Analytics,
**광고 측정** = 제3자 광고 성과 측정. 광고 측정은 Apple 입력 화면의 Third-Party Advertising 및
Developer’s Advertising or Marketing 중 실제 Meta 캠페인 용도에 맞게 매핑해야 한다.
현재 근거는 SceneTrip 설치·전환 측정이므로 Developer’s Advertising or Marketing 해당 여부도 확인한다.
앱 안에 다른 회사 광고가 표시된다고 단정하지 않는다.

### 개인정보 표시에서 놓치지 않을 조건

- `PrivacyInfo.xcprivacy`는 UserDefaults 필수 사유 `CA92.1`만 선언한다. 수집 데이터·추적 선언이
  없다는 사실은 미수집의 증거가 아니다. 최종 앱에 포함된 SDK 매니페스트와 별도로 대조해야 한다.
- Firebase는 이용 통계 기본 ON, IDFA 미사용이다. 회원 여부·언어 속성은 보내지만 앱 회원 ID를
  Firebase 사용자 ID로 설정하지 않는다. 인스턴스 ID가 있으므로 자동으로 비연결 데이터가 되지는 않는다.
- Meta 설정 파일은 `MetaService-Info.local.plist`이며 `MeasurementEnabled` 기본값은 false다.
  실제 제출본에 활성 설정이 포함되는지 미확인이다. 활성 출시 기준으로 IDFA·상호작용의 추적을 예로 작성했다.
- `MetaAnalytics.swift`에는 SDK 18.1.1의 예약 전송·큐 삭제를 공개 API로 취소할 수 없다는 주석이 있다.
  철회 후 새 앱 이벤트 호출을 막는 구현과 방침의 “그 뒤로는 전송하지 않음”이 일치하는지 확인한다.
- 정확도 요청이 100m여도 좌표가 전송 전에 낮은 정밀도로 변환되는 것은 아니다. 정확한 위치를
  미수집으로 확정하지 않는다. 좌표의 요청 처리 후 즉시 삭제, URL·오류 로그 노출 여부와 지도 SDK 동작이 남은 확인 사항이다.
- 발자취는 기본 OFF·동의 후 기기에만 보관하므로 그 기록 자체는 서버 수집에서 제외한다.
  서버에 보관하는 코스 방문 체크·스탬프 기록은 별도로 수집에 포함한다.
- 방침상 AI 가이드 기기 좌표는 서버 주변 검색용이며 기본 모델 대화에서는 제외된다.
  공개 촬영지 좌표와 사용자 실제 위치를 구분한다. 이름·이메일은 모델에 자동 첨부하지 않지만 사용자가
  질문 본문에 직접 개인정보를 적을 가능성은 남는다.

### 심사자가 따라갈 데모 순서

1. 첫 실행에서 English 또는 한국어 선택 → 사용법 완료/건너뛰기 → ATT 허용 또는 거부.

5. 코스 편집 화면의 가이드 진입 버튼 → 여행 질문 전송 → AI 안내에서 `허용하고 계속` → 답변 확인.

## 4. 수출 규정 / Export Compliance

`../Info.plist`에 `ITSAppUsesNonExemptEncryption = false`가 이미 설정돼 있다.
현재 소스의 근거는 HTTPS 등 표준 암호화 사용이며, 비면제 암호화를 사용하지 않는다는 선언이다.
따라서 해당 키는 그대로 유지한다. “암호화를 전혀 사용하지 않는다”는 답변으로 해석하지 않는다.
최종 제출 IPA의 병합된 Info.plist에도 값이 유지되는지와 SDK 추가로 암호화 범위가 바뀌지 않았는지는
제출 담당자가 확인한다. 이번 문서 작업에서 plist는 변경하지 않는다.

| 5 | 커뮤니티 여행후기 상세. 승인된 테스트 글의 대표·본문 사진과 여행 내용이 보이는 상태 | Share your travel story | 여행후기를 함께 나누기 |

- EN·KO 각각 앱 언어를 바꾸고 다시 실행한 뒤 같은 장소·코스·순서로 캡처한다.
  UGC 자동 번역은 없으므로 각 언어로 작성된 촬영용 글을 별도로 준비한다.
- 배포 후보와 같은 기능·서버 데이터로 촬영한다. 로딩·오류·권한 창이 덮지 않은 완료 화면을 사용하고,
  AI 답변·방문 스탬프·리뷰 수를 이미지 편집으로 만들어 넣지 않는다.
- 테스트 프로필은 실제 개인정보가 없는 닉네임을 쓰며 계정 이메일·자격 증명·정확한 개인 위치를 노출하지 않는다.
- 장면 사진·포스터·방문자 사진의 사용 권한과 출처 표시를 확인한다. 장면 사진 권리는
  [ADR 0007](../../../docs/architecture/adr/0007-scene-still-images-pending-rights.md)에서 미결로 남아 있으므로
  제출용 사용 허락을 확인한 사진을 선택한다. 사진이 없는 장면을 포스터로 대체하지 않는다.
- 캡션은 선택 사항이며 원본 앱 화면과 분리해 얹는다. 두 언어 5장씩 동일한 크기로 준비한다.
