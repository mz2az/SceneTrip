# 쓸 수 없는 말 — 리뷰·여행후기·닉네임을 저장할 때 걸리면 거절한다(MZ2AZ-438, docs/project/plans/community-moderation.md §2).
#
# 한 줄에 하나, 띄어쓰기 없이. # 뒤는 주석. 비교는 정규화한 뒤에 한다 — 소문자로, 기호를 빼고(「s.h.i.t」), 한 글자씩
# 띄워 쓴 것을 붙여서(「씨 발」). **낱말 사이 띄어쓰기는 남긴다** — 다 빼면 「도착 시 발권」 이 「시발」 에 걸린다.
# 그래서 이 목록의 말은 한 낱말 안(또는 한 글자씩 띄운 덩어리)에서만 찾는다.
#
# 멀쩡한 낱말 안에 들어가 잘못 걸리는 것은 allowed-words.txt 에 적는다. 흔한 낱말과 겹치는 말(「보지」 — 보지 마,
# 「미친」 — 미친 맛, 「새끼」 — 새끼 고양이, 「씨바」 — 아가씨바다, 「fuk」 — Fukuoka)은 넣지 않는다.
# 운영하며 신고로 들어온 말을 보고 늘린다. 코드를 고치지 않고 이 파일만 바꾼다.
#
# 줄 끝에 ! 를 붙이면 **한 낱말 안에서만** 찾고, 한 글자씩 띄운 덩어리에서는 찾지 않는다 — 「도착 시 발 아파요」 가 「시발」 로
# 붙지 않게. 숫자 바로 뒤의 「시발」(「7시발 KTX」 — N시 출발)은 늘 통과한다(코드가 지운다).
#
# 숫자 끼우기(「씨1발」·「sh1t」)·글자 늘이기(「fuuuck」)는 일부러 잡지 않는다 — 잡으려면 규칙이 커지고 평범한 문장이 다시 걸린다.
# 숫자 뒤 「시발」 예외로 「7시발놈」 처럼 빠져나가는 것, 키릴 문자 섞기(「ѕhit」)도 잡지 않는다.
# 빠져나간 것은 신고로 잡는다. 「시바」 는 「시바견」 때문에 넣지 않는다.
