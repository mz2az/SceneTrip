# contracts/openapi

REST API 명세. 서비스당 파일 하나: `<서비스>-v<메이저>.yaml`

- 명세를 먼저 쓰고 그것이 정본이다. 핸들러가 명세를 따라간다.
- iOS·Android 클라이언트는 이 파일로부터 생성된다 — 앱이 직접 작성하지 않는다.
- 파괴적 변경은 메이저 버전을 올리고 새 파일로 낸다.
  - **예외: 이 계약을 쓰는 앱이 아직 배포되지 않았다.** 깨질 옛 클라이언트가 없으므로 지금은
    제자리에서 고치고 앱·서버를 같은 PR 에서 함께 맞춘다(예: MZ2AZ-296 길찾기 구조 변경,
    MZ2AZ-328 `X-Device-Id` → `X-Install-Id`). 첫 배포부터는 이 예외가 사라진다.
