SCENETRIP / 03

선언한 상태를 계속 맞추는 Kubernetes

  • Deployment: 유지할 이미지와 파드 수
  • Service: 파드가 바뀌어도 같은 주소
  • ConfigMap·Secret: 코드와 실행 설정 분리
강사 노트파드를 지우는 실습은 로컬에 한정한다. DB 볼륨과 파드 수명을 혼동하지 않는다.

DB 준비와 migration

  • UTF8·한글 처리 로케일 검증

강사 노트seed 파일은 수집한 데이터 출처를 확인한 뒤 사용한다. 빈 DB에서 검색 결과가 없는 것은 배포 실패와 다를 수 있다.

localhost와 비밀값의 범위

  • 파드 안 localhost는 그 파드 자신
  • Service DNS는 같은 클러스터의 통신 주소

OpenTelemetry와 OTLP

로컬에서 AWS로 바뀌는 경계

  • kind → EKS, 로컬 이미지 → ECR
  • PostgreSQL StatefulSet → RDS
  • NodePort → ALB HTTPS·Ingress, 원격 관측은 별도 준비
강사 노트마지막으로 한 요청이 지나가는 컴퓨터·네트워크·프로세스를 직접 그리게 한다.
