# canvas — 디자인 캔버스 작업 파일

앱 화면을 스위프트로 옮기기 **전에** 웹에서 먼저 그려 보는 자리다. 여기서 마음에 드는
것이 나오면 그때 `apps/` 로 옮긴다.

| 폴더/파일 | 무엇 |
| --- | --- |
| `_ios.md` | 아트보드가 지키는 값 — 색·글자·간격. 앱 소스에서 잰 것이다 |
| `*.dc.html`, `canvas.json` | 경로여정 탭 캔버스 |
| `brand/` | 마스코트 피노와 첫 실행 온보딩 캔버스 |

## 왜 여기인가

처음에는 저장소 루트의 `design/` 이었는데, `AGENTS.md` §2 가 새 최상위 디렉터리를
금지한다 — 산문·시안은 `docs/<area>/` 가 자리다. 그래서 여기로 옮겼다(2026-08-27).

결정된 내용은 [prd/onboarding.md](../prd/onboarding.md) 가 정본이고, 여기는
그 결정에 도달하는 데 쓴 **시안 작업 파일**이다.
