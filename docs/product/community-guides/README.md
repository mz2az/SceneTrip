# 지역별 성지 여행 추천 가이드

[2026년 10월 자료](regional-guides-2026-10.json)는 같은 도시 안에서 이어지는
가이드 20개, 1일 코스 20개, 사진 첨부 32장이다(MZ2AZ-423). 글은 공식 관광
자료와 블로그를 참고해 새로 썼고 `SceneTrip 추천 가이드`로 표시한다.
개인 방문 경험을 꾸며 쓴 후기가 아니다. 각 글에는 방문 순서·체류 시간·이동
방식·짧게 줄이는 방법·출입 주의·영문 요약·자료 및 사진 원본 링크가 있다.

촬영지와 일반 관광 지점을 구분한다. 장소 3~4개를 같은 지역 안에서 묶었고,
지점 간 최대 직선거리는 18.1km다. 실제 도로 거리·유료 길찾기 결과를 뜻하지
않는다. 제주도도 성산·제주시 동부·서귀포로 나눴다. 영업·휴관·출입 정보는
방문 전에 해당 장소의 현재 안내를 확인하도록 썼다.

사진은 로컬 관광공사 자료의 공공누리 제1유형 표기·원본 주소·좌표를 대조했다.
원본 바이트와 출처를 보존한다. 150×100 사진 2장은 제외했고, 좌표가 불확실한
김녕 사진도 사용하지 않았다. 보목포구와 전동성당 참고 풍경은 실제 피사체를
본문에 적어 야자수길·한벽굴 자체의 사진과 혼동하지 않게 했다.

## 적재와 유지

블로그형 본문과 [AI 변환 사진 제작 이력](ai-images/README.md)은 MZ2AZ-428에서 추가했다.
기존 글·코스 ID와 원본을 보존하는 [적용 절차](../../ops/community-blog-local.md)를 따른다.

[로컬 준비·검증 절차](../../ops/community-guides-local.md)를 따른다. 자료 파일을
커밋하는 것과 서버에 실제로 게시하는 것은 별개다. 이번 적재는 로컬 kind DB와
MinIO에만 적용한다. 다른 DB나 운영 서버로 자동 전파하지 않는다. 준비 상태와
생성 ID는 저장소 밖에 보관하고, 같은 상태 파일로 재개해 글을 중복 생성하지 않는다.

기존 기기 글 2개와 사진 5장은 새 가이드에 합치거나 서버에 공개하지 않는다.
[보존 계획](../../project/plans/community-regional-guides.md)과
[검증 결과](../../qa/community-guides-verification.md)를 함께 본다.
