# 커뮤니티 가이드 AI 변환 사진

사진 31종을 가이드 20개의 첨부 32장으로 사용한다(MZ2AZ-428). 내장 이미지 생성
도구로 관광공사 제1유형 원본의 구도·빛을 조정하고 인물을 제거했다. 실제 장소의
특징을 대조했으며 지동 주소판과 광안리 조형 글자가 잘못 생성된 판은 구도를 다시
잡아 제외했다. 경기전 출처 글자는 보정했다. 원래 관광 자료의 전동성당 정원 사진은
실제 피사체를 설명하는 캡션으로 표시한다.

[manifest.json](manifest.json)에 원본 URL·자료 ID·이용 유형·출처·입력/출력 SHA256,
생성 프롬프트·파일 크기·가이드와 사진 순서가 있다. 최종 JPEG 합계는 약 21.9MB다.
기존 첨부의 원본 해시도 적용 전에 대조한다. 설명과 출처에는 AI 변환을 표시하며,
현장 방문 인증·현재 간판이나 영업 상태를 증명하는 사진으로 사용하지 않는다.

[로컬 적용 절차](../../../ops/community-blog-local.md)로 원래 글 ID·코스 사본과
원본 객체를 보존하며 새 저장 키를 붙인다. 생성 PNG·보정 전 판·실행 상태·백업은
저장소 밖에 보존한다. 운영 저장소에 자동 업로드하지 않는다.
