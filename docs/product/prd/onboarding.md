# 첫 실행 — 스플래시 · 마스코트 · 사용법

> 정한 사람: 정승길 · 2026-08-23
> 시안: [마스코트와 온보딩 캔버스](https://claude.ai/code/artifact/a2aeef5c-9355-4881-8794-928526d10d45)
> 코드: `apps/scenetrip-ios/src/Onboarding/`

## 무엇이 문제였나

앱을 열면 **흰 화면 다음에 곧바로 지도**가 떴다. 둘이 문제다.

우선 **우리 앱이 무엇인지 말하는 자리가 없었다.** 지도와 검색창만 보고 「K-콘텐츠
촬영지를 찾아 주는 앱」이라고 알아차릴 사람은 이미 아는 사람뿐이다.

그리고 **기능을 아무도 안 알려 준다.** 행마다 붙은 「길찾기」 버튼이 그 자리에서
현재 위치부터 안내를 시작한다는 것, 코스를 AI 가 짜 준다는 것, 반경 안의 음식점을
함께 띄운다는 것 — 전부 눌러 보기 전에는 모른다. 첫 사용자는 누를 이유를 모른다.

## 누구를 위한 것인가

한국에 온(또는 오려는) **외국인**이다. 한국어를 못 읽는 경우가 기본이다.

## 무엇을 하나

```
앱 실행 ─→ 스플래시 (1.9초) ─┬─ 첫 실행이면 → 사용법 넉 장 ─→ 앱
                              └─ 두 번째부터 ───────────────→ 앱
```

### 스플래시

지도 핀이 위에서 떨어져 꽂히고, 그 핀이 고양이다. 워드마크와 한 줄이 뒤따른다.

**없던 기다림을 만드는 것이 아니다.** `SceneTripApp.init` 이 지도 SDK 인증과 서버
주소를 세우고 첫 화면이 인기 촬영지를 부르는 동안, 지금까지는 흰 화면이 보였다.
스플래시는 그 자리를 덮는다 — 그래서 `AppRoot` 는 진짜 앱을 **밑에 깔아 두고**
스플래시를 위에 얹는다. 덮개가 걷힐 때 화면은 이미 그려져 있다.

### 사용법 넉 장

앱이 실제로 하는 일이 넷이라 넉 장이다. 다섯 장을 넘기면 사람이 건너뛴다.

| 장 | 말하는 것 | 근거 |
| --- | --- | --- |
| ① Where the scene was filmed | 작품 이름으로도, **장면 설명**으로도 검색 | `c8c422d` (MZ2AZ-263) |
| ② Set your pace. PINO plans the days. | 빡빡 하루 5곳 · 널널 3곳 | `RoutePlanner.perDay` |
| ③ Tap Directions when you feel like going | 그 자리에서 눌러 대중교통+도보 안내 | `KakaoTransit` · `TmapWalk` |
| ④ Eat on the way. Ask when you are stuck. | 반경 POI 넷 + 챗봇 | `RouteNavMock.tone` · `V12__poi.sql` |

각 장의 수치는 **지어낸 것이 아니라 코드에서 가져온 것**이다. `perDay` 를 고치면
②의 문구도 함께 고쳐야 한다.

## 정한 것

### 마스코트는 지도 핀이다

새로 그린 그림이 아니다. `PinImage.numbered` 가 그리는 물방울(머리 원 r14 @ (19,17),
꼬리 (19,45))을 세 배로 키우고 귀·얼굴·꼬리만 붙였다. 얼굴이 앉는 흰 원은 지도에서
번호 ①②③ 가 앉던 **그 배지와 같은 자리**다.

그래서 검색 탭을 켜면 마스코트가 155개 흩뿌려져 있는 셈이 된다. 마스코트 따로,
지도 따로가 아니다. 새로 들인 색도 **둘뿐**이다 — 분홍(귀 속·볼) `#F7A8C0`,
눈동자 `#4A3FA8`.

### 이름은 피노 / PINO

`PIN` + `o`. 지도 핀에서 나온 고양이라 이름도 핀에서 나온다. 영어권·일본어권·중국어권이
모두 그대로 읽고, 어느 나라 말에도 걸리는 뜻이 없다 — 외국인 대상 앱에서 이것이 가장 컸다.

고르지 않은 것: **씬냥** (가장 한국적이지만 영어권이 발음을 못 한다), **묘 MYO**
(뜻에 설명이 붙어야 한다), **컷 CUT** (고양이와 이어지지 않는다).

표기는 영어 UI 에서 `PINO`, 한국어 문서에서 `피노`, 코드 식별자는 `Pino`.

### 사용법은 영어가 본문이다

외국인이 쓰는 앱이니 처음 여는 화면부터 영어여야 한다. 한국어는 아래 흐린 보조줄로
남겨 팀이 검수할 때 읽는다.

**본체 UI 의 영문화는 여기 범위가 아니다.** 넷째 장을 넘긴 순간 말이 바뀌는 것은
알고 있고, 그것은 아래 「남은 일」에 적었다. 온보딩만 먼저 영어인 편이 둘 다 한국어인
것보다는 낫다.

### GIF 가 아니라 벡터로 그린다

SwiftUI 에는 GIF 재생이 없다. 셋을 견줬다.

| 방법 | 새 의존성 | 문제 |
| --- | --- | --- |
| GIF + `CGAnimateImageAtURLWithBlock` | 없음 (ImageIO 내장) | GIF 는 **256색** — 하늘→보라 그러데이션에 띠가 진다 |
| Lottie | **있음** (`MODULE.bazel`) | 애니메이션 하나에 라이브러리를 들인다 |
| SwiftUI `Path` | 없음 | — |

세 번째로 갔다. 의존성 0, 용량 0, 어느 배율에서도 선명하다. 발표자료·스토어용 GIF 가
필요하면 같은 그림을 웹 캔버스에서 뽑는다.

## 하지 않을 것

- **로그인·회원가입을 붙이지 않는다.** 지금 신원은 `InstallIdentity` 의 설치본 UUID 하나다.
- **언어 선택 화면을 넣지 않는다.** 넣을 자리는 여기가 맞지만, 고를 언어가 아직 하나뿐이다.
- **권한 요청을 여기서 하지 않는다.** 위치 권한은 필요한 순간에 묻는 것이 승낙률이 높다.
- **건너뛰기를 없애지 않는다.** 넷째 장까지 강제로 보게 하지 않는다.
- **본체 UI 를 영문화하지 않는다.** 별도 일감이다.

## 다시 보여 주는 규칙

`UserDefaults` 의 `scenetrip.onboarding.seenVersion` 에 **판 번호**를 남긴다.
`true`/`false` 로 두면 튜토리얼을 통째로 갈아도 이미 깔린 사람은 영영 못 본다.
판을 올리면 그 사람들에게 한 번 더 보인다 — 문구를 다듬는 정도로는 올리지 않고,
장이 늘거나 기능이 바뀌었을 때만 올린다.

마이페이지에 **「사용법 다시 보기」** 를 두었다. 첫 실행에 한 번 지나가는 화면이라
다시 여는 문이 없으면 두 번 다시 못 본다.

## 성공을 무엇으로 보나

지금은 **재는 장치가 없다.** 아래는 계측을 붙일 때의 목표값이고, 붙이기 전까지는
지표가 아니라 의도다.

| 지표 | 목표 |
| --- | --- |
| 넷째 장까지 본 비율 | 60% 이상 |
| 첫 세션에 검색을 한 번이라도 한 비율 | 70% 이상 |
| 첫 세션에 「길찾기」를 누른 비율 | 25% 이상 |
| 스플래시에서 이탈 | 1% 미만 |

## 남은 일

- **본체 UI 영문화.** 넷째 장을 넘기면 한국어로 바뀐다. 티켓이 필요하다.
- **챗봇 무료 횟수.** ④가 챗봇을 약속하는데 무료 횟수 제한이 지라에도 계약에도 없다.
- **계측.** 위 지표를 재는 이벤트가 아직 없다.
- **커뮤니티·마이페이지 탭.** 아직 `StubTab` 이다. 마이페이지에는 「사용법 다시 보기」만 얹었다.
