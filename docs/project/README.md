## 계획을 파일로 두는 이유

모듈 둘 이상에 걸치거나, 계약을 바꾸거나, 의존성을 추가하거나, 대략 100줄을 넘는 변경은
먼저 여기에 계획을 쓴다. 저장소 안의 계획은 리뷰하고, 고치고, 몇 주 뒤 다른 사람이 —
사람이든 AI 든 — 이어받을 수 있다. 채팅창의 계획은 그럴 수 없다.

오래 영향을 남기는 결정은 [ADR](../architecture/adr/README.md) 로 승격한다.
