# iOS AI 기능 동의 (MZ2AZ-468)

## 범위와 흐름

- iOS의 가이드 질문·재시도와 AI 코스 만들기 직전에 공통 안내 시트를 표시한다.
  앱 시작·가이드 열기·마법사 진입만으로는 표시하거나 AI 요청을 보내지 않는다.
- 입력·대화·관심 작품·여행 조건·코스 맥락의 Amazon Bedrock(AWS) 미국 오리건 전송,
  이름·이메일 제외, 답변 오류 가능성을 한·영으로 알리고 `LegalLinks.privacy`를 연결한다.
- 허용하면 두 기능을 함께 사용할 수 있다. 취소·끌어 내려 닫기는 진행하지 않으며
  질문 입력과 마법사 선택값을 보존한다. 허용 후 시트가 닫힌 다음 대기 중 동작을 한 번 실행한다.
- 마이페이지 이용 통계 설정 바로 아래에 AI 기능 토글을 둔다. 끄면 동의를 철회하고,
  다시 켤 때도 같은 안내를 확인한다. 다른 기능과 통계 설정에는 영향을 주지 않는다.

## 구현

- `Models/AIConsent.swift`: 주입 가능한 저장소, UserDefaults의 동의 버전, 공통 UI 게이트.
  저장값이 현재 안내 버전과 정확히 같을 때만 허용하며, 안내 변경 시 버전을 올린다.
- `Models/AIConsentSheet.swift`: 스크롤 가능한 공통 시트와 표시 modifier.
- `ProfileTab/ProfileAISettings.swift`: 동의 버전을 관찰하는 설정 토글. 큰 마이페이지
  본체에는 이 뷰를 이용 통계 설정 바로 다음에 배치한다.
- `Models/RetryingSession.swift`의 `RetryTask.send`: 생성 클라이언트가 사용하는 세션에서 `/guide/chat`과
  `/guide/plan`의 매 전송(인증 갱신 후 재전송·자동 재시도 포함) 전에 동의를 검사한다.
  미동의는 `AIConsentRequired`로 끝내며 안쪽 네트워크 세션을 만들지 않는다.
  첫 검사 뒤 철회되면 전송 직전 저장소 잠금 안에서 재검사해 시작을 막고 만든 task는 취소한다.
  이 잠금은 `revoke()`와 공유하며 await를 포함하지 않는다.
- 새 소스와 시험은 iOS `BUILD.bazel`에 명시한다. 서버·계약·에이전트는 변경하지 않는다.

## 검증

- 가짜 저장소·전송 세션으로 미동의 차단/시트 요청, 허용 후 진행, 취소와 입력 보존,
  철회 후 재확인, 버전 변경, 두 기능의 동의 공유, 다른 API 유지, 재시도 중 철회를 검사한다.
  `testRevocationAfterConsentCheckPreventsTaskResume`는 첫 검사 뒤 `fault`에서 철회해
  두 AI 경로 모두 실제 전송 시작이 0회이고 동의 오류로 끝나는지 검사한다.
- 사용자 요청에 따라 빌드·시험·`just check`는 실행하지 않는다. 변경 Swift 파일만
  swiftformat으로 정리하고 정적 검토한다. 최종 게이트 실행은 사용자가 맡는다.
- 단위 시험 10개를 추가했다. 최초 변경 Swift 파일 11개에 swiftformat을 적용했고 SwiftLint 오류는
  0개다(기존 파일의 길이·복잡도 등 경고 14개). 한·영 문자열은 `plutil` 구문 검사,
  변경 내용은 Git 공백 검사를 통과했다. 컴파일·시험 통과를 뜻하지 않는다.
- 후속 UI 확인: 한·영 및 큰 글자에서 본문·링크·버튼, 채팅/마법사 취소 후 입력 유지,
  설정 토글과 재실행 시 저장 상태를 확인한다. 실제 AI API 호출은 이번 작업에서 금지한다.
