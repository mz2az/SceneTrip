# Android 포스터·홈 선반·닉네임 동기화 (MZ2AZ-431)

iOS PR260의 main `8378ade`를 기준으로 Android만 맞춘다. 이전392의 포스터Fit 결정은
431의 최신 고정 칸 중심Crop으로 대체한다. 장소·실제 씬 사진의 전체 비율 규칙은 유지한다.
서버·계약·iOS 소스, 사용자 root 변경과 원래 계정·후기·사진·코스는 수정하지 않는다.

## 변경

- 홈·작품 목록·자동완성의 포스터는 고정 크기를 채운다. 작품 상세는 iOS와 같은
  가로 전체·높이176dp 포스터, 그 아래 메타·출연을 배치한다. 상세 제작사 HTTP(S) 연결은 유지한다.
- 홈 인기순 첫20편 순서와 수평 선반/세로 홈 스크롤을 실제 Android에서 확인한다.
- 홈의 원은 행 밖으로 나온 부분도 터치할 수 있게 전체 화면 부모에 그리되 원래 측정 위치를 따른다.
  전체 보기는 이전 작품·촬영지·씬 상세와 검색 조건을 지워 작품 목록을 연다. 일반 탭 선택은 상태를 보존한다.
- 닉네임은 해태와 작성자 미리보기·NFC 글자 수·지우기·스크롤 본문·하단 저장/취소를 제공한다.
  큰 글자와 키보드에서는 큰 시트, 저장 중 입력·닫기 잠금. Dialog 밖에 입력·작업 상태를 둔다.
- 서버 닉네임 응답의 기존AccountReply/epoch 검사는 유지하고, UI도 요청epoch가 바뀌면
  닫기·오류 표시·질문 이력을 갱신하지 않는다. 동일 이름은 정하기에서만 서버 없이 시작한다.

## 검증과 경계

닉네임 변경 가능 여부·자동 이름·NFC·저장 중 중복·늦은 성공/실패·예외를 단위 시험으로 먼저 확인한다.
새 소스·시험·별도 UI 시험기의 BUILD를 갱신한다. 별도 QA APK의 모의 이름/저장 응답으로
라이트/다크·한국어/영어·큰 글자·키보드·취소/잠금 UI를 검사하며 실제 OAuth/회원 저장으로 간주하지 않는다.
제품 홈·목록·상세 포스터는 서버 재기동 완료 통지 뒤 공개 읽기만으로 확인한다.
유료 가이드·길찾기·외부 계정 로그인·DB seed/reset은 하지 않는다. `just check`, PR CI와 로그 확인 후 병합한다.
428 bodyBlocks는 해당 계약 main 반영 후 별도 브랜치에서 소비한다. Jira 연결은 담당자의 갱신 뒤 복구됐다.
