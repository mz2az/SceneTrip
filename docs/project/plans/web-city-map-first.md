# 웹 — 첫 화면 도시를 누르면 지도부터 (코스 만들기는 그다음)

- **상태**: 구현 중(2026-11-14). 새 화면이라 dev 먼저, 사용자 확인 뒤 main.
- **왜**:
  - 지금 첫 화면 「어디로 여행 가세요?」 의 도시 칩(서울 124·부산 19 …)을 누르면 곧바로 코스 만들기(며칠 → 어떻게 → AI)로 간다.
  - 광고로 처음 온 사람에게 결정을 너무 일찍 묻는다. 코스 만들기는 오른쪽 아래 떠 있는 「여행 계획」 버튼에 이미 있다.
  - 사용자 제안(2026-11-14): 「그 지역에 음영을 칠하고 그 124개 위치를 지도로 보여 주는 게 낫다」.
  - 홈 시안 A 는 권호가 만들었다(11/7) — 바뀐다고 알린다.

## 1. 흐름

1. 첫 화면 도시 칩을 누르면 작품검색 탭의 지도로 간다.
   - 그 도시 촬영지를 감싼 범위로 「현 지도 내 성지 검색」 을 건다. 결과가 오면 핀에 맞춘다(지금 「지도에서 보기」 와 같은 길, `router.openRegion`).
   - 그 도시 촬영지를 감싼 영역에 옅은 색을 칠한다(§2).
   - 지도 위에 도시 카드를 띄운다 — 「서울 촬영지 124곳」 + 「이 도시로 코스 만들기」 + ✕.
2. 「이 도시로 코스 만들기」 를 누르면 지금의 도시 코스 만들기(며칠부터)가 열린다(`protoActions.plan(key)`).
3. ✕ 를 누르거나 탭을 떠나면 색칠과 카드를 지운다. 지역 필터도 지금처럼 지운다.
4. 첫 화면 문구를 바꾼다.
   - 한국어: 「도시를 고르면 그곳 드라마·영화 촬영지를 지도로 보여 드려요」
   - 영어: 「Pick a city to see its K‑drama spots on the map.」

## 2. 칠할 영역 — `cityShade(places)` (`features/home/cityShade.ts`, 순수 함수)

시험은 이 절과 §3 만 보고 쓴다.

- 입력은 `{ latitude, longitude }[]` 이고, 출력은 `{ lat, lng }[]`(닫지 않은 고리, 시계 반대 방향) 또는 `null` 이다.
- 서로 다른 점이 0개면 `null` 이다.
- 서로 다른 점이 3개 이상이고 한 줄에 있지 않으면 볼록 껍질(convex hull)을 쓴다.
  - 껍질의 각 꼭짓점을 무게중심에서 바깥으로 15% 밀어 넓힌다. 가장자리 핀이 경계에 걸리지 않게 하려는 것이다.
  - 넓힌 뒤에도 각 꼭짓점이 무게중심에서 최소 0.005도(약 500 m) 떨어지게 한다.
- 점이 1~2개이거나 모두 한 줄에 있으면 그 점들을 감싼 상자를 0.01도 넓힌 직사각형(꼭짓점 4개)이다.
- 같은 좌표가 여러 번 있어도 한 점으로 본다.

## 3. 지도에 칠하기 — `MapLayer.addPolygon(spec)` (`src/map/types.ts`)

- `PolygonSpec = { path: LatLng[]; fillColor: string; fillOpacity: number; strokeColor: string; strokeWeight: number; strokeOpacity?: number }`
- 돌려주는 값은 `{ remove(): void }`(`PolylineHandle` 과 같다).
- 그리기 구현은 둘이다.
  - 네이버: `maps.Polygon`, 클릭은 받지 않는다.
  - Leaflet: `L.polygon`, `interactive: false`.
- 레이어의 `clear()`·`remove()` 가 다각형도 지운다.
- 색: 채움 `#7A69ED`(앱 보라) 불투명도 0.12, 테두리 같은 색 0.6, 굵기 2.

## 4. 이벤트 (web-proto-events.md 에 더한다)

- 도시 칩: `select_home_city(city, 'proto_chip')` 그대로 보낸다. `plan_start('city_chip')` 은 보내지 않는다 — 이제 칩은 코스를 시작하지 않는다.
- 지도 카드의 「이 도시로 코스 만들기」: `plan_start` 의 `entry` 에 새 값 `city_map`.
- 지도 카드의 ✕: `home_tap` 이 아니라 새 이벤트를 만들지 않는다(필요해지면 더한다).

## 5. 하지 않는 것

- 실제 시·도 행정 경계선 — 필요하면 다음 차례에 공공데이터 경계로 바꾼다.
- 옛 홈(`HomeCitySpots`)은 그대로 둔다(시안이 꺼진 경우만 보인다).
