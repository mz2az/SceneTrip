# Android iOS 동기화 — 2026-10-13 (MZ2AZ-148)

## 기준과 보존

main `2e4cccd`, iOS PR #242와 지역 가이드 PR #250을 기준으로 기존 Android 구현의 누락만 반영한다.
기존 Android 세션과 격리 작업 트리를 재사용한다. root의 사용자 변경 22개는 저장소 밖 해시 기록으로
보존하며 stage·stash·삭제하지 않는다. iOS Simulator와 계정·원본 사진은 조작하지 않는다.
지역 가이드 20개·사진32장·코스20개는 이미 적재되어 있어 다시 생성하거나 적재하지 않는다.

## 작업과 검증

### 중지 후 재개

PR #253 이후 재개 기준은 main `b9711c7`이다. 기존 작업 폴더의
`MZ2AZ-148-android-resume-oct13` 브랜치에서만 작업한다.
MZ2AZ-431의 포스터 fill·홈 선반·닉네임과428의 블로그 본문은 iOS 담당의 main 반영 뒤
Android에 동기화하며, 지금 iOS·서버·계약을 수정하지 않는다. 공통 API 재기동·DB 적용도
담당자가 알린 뒤 소비하고 기존 후기·코스는 변경하지 않는다.

1. 글자 배율 변경 중 코스 마법사의 단계·답변·편집 초안이 사라지는 오류를 실제로 재현한다.
   Android fontScale 구성 변경과 Dialog의 상태 소유 위치를 함께 수정하고,
   별도 instrumentation으로 제품 앱의 저장하지 않은 시험 초안만 검증한다.
2. 코스 지도는 검색 지도의48% 카메라 상한을 공유하지 않는다. 실제 지도 높이와60% 패널을
   기준으로 보이는 영역을 계산하고 iOS 코스와 같은40dp 맞춤 여백을 적용한다.
   검색의 기존24dp/48% 규칙은 유지하며, 작은 지도·최대 패널에서 잘못된 영역을 방지한다.
3. 글자 크기·라이트/다크와 POI 상태의 Android 화면을 추가 확인한다. 유료 가이드/길찾기,
   실제 OAuth/GPS를 시험 응답이나 컴파일 결과로 완료 처리하지 않는다.

새 소스·시험·QA 레시피의 BUILD를 갱신하고 `just check`, 실제 Android 화면과 PR CI 로그를
확인한다. 다른 세션의 Simulator·계정·DB 후기/코스와 root 미커밋 변경은 보존한다.
