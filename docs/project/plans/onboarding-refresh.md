# 사용법 안내를 현재 기능과 맞추기 — MZ2AZ-399

2026-10-11 사용자가 실행 가능한 백로그의 구현을 승인했다. 기존 사용법의 네 장,
순서와 해태 삽화를 유지하고 기능 설명과 접근성을 고친다. Android는 별도 후속이다.

## 확인한 문제

- AI 일정의 주 실행 경로는 `agents/trip-guide/config/llm_planner.json`이다. 방문 개수를
  정하지 않고 속도·지역 안 동선을 모델에 준다. 결정적 엔진의 최대 7/3곳을 모든
  AI 결과의 약속처럼 온보딩과 마법사에 적으면 잘못된 안내가 된다.
- 넷째 장의 「한국어는 해태가 맡습니다」는 여행 가이드 범위를 설명하지 않는다.
- 이전 버튼이 없어 앞장을 다시 읽으려면 스와이프를 알아야 한다.
- 고정 크기 글자·300pt 그림·50pt 버튼과 스크롤 없는 본문은 작은 화면과 큰 글자에서
  내용이 잘리기 쉽다. 완료를 연속 누르면 분석 완료 이벤트가 중복될 수 있다.

## 적용

검색 → AI 초안 → 길찾기 → 주변 시설·여행 질문의 네 장을 유지한다. 두 번째 장은
원하는 속도와 가까운 촬영지로 초안을 만들고 편집할 수 있음을 설명한다. 방문 수를
약속하지 않는다. 마법사 속도 선택 설명도 같은 규칙으로 맞춘다. 넷째 장에서는
가이드에게 촬영지·여행 계획을 물을 수 있음을 설명하고 실시간 날씨·통역을 약속하지 않는다.

각 페이지는 스크롤하고 본문은 Dynamic Type을 따른다. 그림은 화면 폭에 맞추며
아래 이전·다음·시작하기는 safeAreaInset으로 본문과 분리한다. 페이지 진행 규칙과
완료 중복 방지는 별도 값 모델로 시험한다. 기존 사용법 확인 판 번호는 유지한다.

## 검증과 한계

진행 범위·이전/다음·완료 중복·건너뛰기 규칙의 실패 시험 후 구현한다. 기존 첫 실행/
다시 보기 시험, iOS 단위 시험과 `just check`, PR CI를 수행한다. 최종 통합 앱에서
한국어·영어, 작은 화면·큰 글자, 끝내기·건너뛰기를 조작한다. 실제 조작을 수행하지
못한 경우 코드·단위 확인과 분리해 기록한다. 기존 앱 데이터는 삭제하지 않는다.

새 이미지나 완전히 다른 시안은 지정되지 않았다. 이 변경은 기존 시안의 실제 기능 설명과
사용 가능성을 고치며 새로운 브랜드 디자인을 확정한 것으로 취급하지 않는다.
