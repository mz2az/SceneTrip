# iOS 포스터·홈 작품 스크롤·닉네임 화면 (MZ2AZ-431)

2026-10-13 사용자 요청. 원본 비율을 모두 보이던 포스터가 고정 칸 안에서 여백을
만들어, 이전처럼 정해진 칸을 채우도록 복구한다. 중심 정렬과 작품 상세에서만
제작사 페이지를 여는 규칙은 유지한다. 홈·검색 목록·자동완성·작품 상세가 대상이다.
관광공사 장소 사진의 비율·출처 표시는 유지한다. 포스터 비율 통일 수집은 후속이다.

## 홈 작품 선반

최신 main의 「지금 뜨는 작품」 좌우 이동과 작품 선택을 실제 iOS 화면에서 확인한다.
서버 인기순 첫 20편, 세로 홈 스크롤, 「내 여행 이어가기」의 여러 코스와 독립적으로
움직여야 한다. main에는 예전 UIKit 페이지 컨트롤러 대신 SwiftUI 수평 스크롤을
쓰는 수정이 이미 있다. 팀원이 보고한 증상의 플랫폼·OS·기기·코스 개수·재빌드
조건을 대조한다. 재현되지 않은 원인을 확정하거나 수정했다고 기록하지 않는다.

## 닉네임

마이페이지 변경·가입 후 정하기를 같은 최신 카드 구성으로 맞춘다. 공개되는 이름의
미리보기, 입력란과 16자 표시, 기존 형식/예약 이름/중복/저장 실패 안내를 보여 준다.
스크롤 본문과 하단 저장·취소를 분리해 키보드·큰 글자·작은 화면에서도 접근할 수 있게
한다. 저장 중 입력·닫기를 잠그며 계정이 바뀐 뒤 돌아온 응답으로 창을 닫지 않는다.
2~16자·NFC·허용 문자, 자동 닉네임 그대로 시작/건너뛰기, API와 소유 규칙은 유지한다.

## 검증

기존 닉네임·인증·제작사 링크·홈 인기순 단위 시험과 `just check`를 통과시킨다.
작은/큰 iOS 화면의 가로 스크롤 전후 좌표·첫/뒤 작품·다시 돌아오기, 포스터 여백 제거,
닉네임 입력·취소·키보드·라이트/다크·큰 글자를 확인한다. 사용자 원본 기기 자료와
시안 22개를 보존한다. 별도 검증 에이전트 검토·CI 후 PR/main으로 반영하고
MZ2AZ-363·392에 후속 결정과 실제 결과를 남긴다. 블로그 작업 MZ2AZ-428은 별도다.
