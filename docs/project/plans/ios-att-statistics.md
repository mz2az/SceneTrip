# iOS ATT와 이용 통계 설정 (MZ2AZ-402)

2026-10-15 제품 결정에 따라 첫 출시부터 ATT를 요청한다. iOS 앱만 변경하며
Firebase GA4의 IDFA 없는 제품과 기존 Meta 설정 파일 조건은 유지한다.

## 구현 순서

1. 주입 가능한 ATT 요청 조정자와 통계 설정의 단위 시험을 먼저 작성한다.
2. 스플래시·온보딩이 끝난 활성 화면에서 전환 애니메이션 뒤 ATT를 요청한다.
   기존 온보딩 완료 사용자도 같은 경로로 진입한다. 시스템이 답한 권한은 다시 묻지
   않고, 요청 중 또는 같은 실행의 중복 요청도 막는다. 시스템이 미결정으로 돌려주면
   이번 실행에서는 다시 묻지 않고 다음 실행에서 시스템 상태를 다시 확인한다.
3. 이용 통계 기본값은 ON이며 UserDefaults에 저장한다. OFF이면 Firebase 이벤트와
   사용자 속성, Meta 초기화·활성화·이벤트를 막는다. OFF로 시작하면 Firebase를
   초기화하지 않고, ON 전환 때 지연 초기화한다. 이미 초기화한 Firebase는
   `Analytics.setAnalyticsCollectionEnabled(false)`로 자동 수집까지 끈다.
4. 마이페이지 도움·정책 근처에 통계 토글·설명과 ATT 상태/설정 이동을 추가한다.
   앱 기능은 제한하지 않는다. 한국어·영어 번역과 InfoPlist 권한 문구를 함께 넣는다.
5. BUILD의 기존 glob 포함 여부와 README를 갱신하고 변경한 Swift 파일만 포맷한다.

## 문구와 범위

제공된 공개 개인정보처리방침 사본의 4·5항과 맞춘다. Firebase는 이용 통계,
Meta는 ATT 허용 시 광고 성과 측정이다. 통계를 꺼도 앱 기능은 유지한다.
기존 서버 인기도 기록(UsageEvents)은 Firebase·Meta 설정과 별도이며 변경하지 않는다.
권한 창은 시스템 언어의 InfoPlist.strings를 사용하므로 실행 중 앱 언어 변경은
다음 실행부터 시스템 권한 문구에 반영되는 기존 제약을 따른다.

## 검증

- 리뷰 보완: Meta flush를 클라이언트 경계로 분리해 ON·ATT 허용 조건과 OFF 시
  disable·flush 없음, 미초기화 시 SDK 호출 없음을 검사한다. ATT 문구는 설치와
  장소 저장·코스 만들기의 광고 성과 측정 범위로 맞춘다.
- 알려진 한계: OFF 직전에 SDK 에 이미 넘긴 이벤트의 비동기 전송은 SDK 18.1.1 공개 API 로
  취소할 수 없다. 넘기는 것은 ATT 허용 + 통계 ON 일 때뿐이다.
- 단위 시험: 온보딩·활성 조건, 중복 요청, 기존 응답, 허용·거부·제한·미결정,
  요청 중 통계 OFF, 저장값 복원, Meta 차단과 재활성화, Firebase 입구 차단,
  한국어·영어 권한 리소스.
- `just check` 통과(2026-10-15).
- 실기기 확인: 신규/업데이트 설치, 스플래시 중 백그라운드 전환, ATT 응답 후
  재실행, 기기 전체 추적 요청 OFF, 마이페이지 통계 OFF/ON과 재실행,
  설정에서 ATT 철회 후 복귀, 한국어·영어 문구와 큰 글자 배치.
