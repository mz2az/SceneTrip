# iOS 상세 사진·작품 연결과 남은 프론트 검증

상위 프론트 스토리 [MZ2AZ-148](https://mz2az.atlassian.net/browse/MZ2AZ-148)의
후속 작업이다. 2026-10-12 사용자가 씬 사진 확대, 작품 상세 포스터 연결, 남은
프론트 작업과 이미 구현된 지라 항목의 완료 조건 대조를 요청했다.

## 범위

| 티켓 | iOS에서 처리할 내용 |
| --- | --- |
| MZ2AZ-392 | 작품 상세의 포스터만 서버 `producerUrl`의 제작사 페이지로 연결 |

Android 구현은 별도 세션이 담당한다. 서버의 제작사 URL 계약은 main에 들어온
MZ2AZ-393 구현을 사용하며 계약·생성 클라이언트를 다시 정의하지 않는다.
원래 작업 폴더의 다른 사용자 미커밋 파일은 보존한다.

## 화면과 데이터 규칙

- 포스터 링크는 HTTP(S) 절대 주소만 허용한다. 상세 응답이 도착하면 그 응답이
  정본이다. 주소가 없으면 포스터는 이미지로 남는다. 작품 목록의 선택 동작은 유지한다.
- 씬 뷰어의 입력은 `sceneImageUrl`뿐이다. 포스터와 다른 장소 사진을 대신 쓰지 않는다.
  주소가 없는 카드에는 확대 동작이 없다. 설명은 기존 시트에서 계속 볼 수 있다.
- 뷰어는 UIKit의 사진 스크롤·확대 동작을 사용한다. 전체 그림을 화면에 맞추고,
  두 손가락·두 번 누르기·접근 가능한 버튼으로 확대한다. 사진을 바꾸거나 화면 크기가
  바뀌면 맞춤 배율로 돌아온다. 닫은 뒤 상세의 스크롤 위치는 그대로 유지한다.
- 사진의 실패는 안내와 수동 재시도로 처리한다. 사진첩의 메모리 디코딩과 기존 리뷰
  사진 업로드·서명 주소 규칙은 유지한다. 계약에 출처가 있으면 원문을 보존한다.
- 장바구니의 작품 출처는 작품 상세에서 담을 때만 전달한다. 일반 장소 담기는
  작품을 추정하지 않는다. 테스트 데이터는 별도 설치 식별자로 구분한다.
- 닉네임은 서버가 미확정이라고 하고 그 계정에 질문한 기록이 없을 때만 묻는다.
  늦게 도착한 `/me` 응답이 로그아웃·다른 계정을 되살리지 않도록 세션을 확인한다.
- 앱 테마의 기본값은 시스템이다. 선택은 기기에 저장하고 시트·덮개까지 적용한다.

## 검증과 지라 정리

1. 기존 홈 정렬의 회귀 테스트를 먼저 실패시킨다. URL·사진 입력·확대 기하·테마·
   닉네임 경계는 외부 서비스 없는 단위 검사로 확인한다.
2. `just check`를 통과한 뒤 별도 iOS 시험 기기에서 실제 작품 상세, 씬 사진 확대,
   재시도, 닫기·연속 열기, 라이트·다크·큰 글자와 기존 리뷰 사진첩을 확인한다.
3. 장바구니 출처·조회·중복·삭제·헤더 누락과 리뷰 사진의 서버 저장을 로컬에서
   대조한다. 사용자 코스·리뷰·사진·로그인 세션은 시험용으로 변경하지 않는다.
4. 로컬 DB의 이전 미공개 시험 마이그레이션을 공식 main과 대조하고 백업·검증한
   뒤 로컬 서버를 갱신한다. AWS 배포·공유 DB 변경은 수행하지 않는다.
5. 이미 구현된 열린 티켓은 완료 조건·테스트·실제 검증 근거를 대조한다. Android,
   운영 설정 또는 실기기 확인이 남은 티켓은 완료 처리하지 않고 남은 조건을 적는다.
6. CI가 통과한 PR로 main에 반영하고 기존 사용자 변경을 보존해 로컬 main을 갱신한다.

## Apple 로그인과 출시 조건

2026-10-12 로컬 서버의 Apple 개인 키와 토큰 암호화 키가 비어 있고 `/auth/apple`이
501을 반환함을 확인했다. 시뮬레이터 Apple 계정 로그인만으로 서버 설정은 채워지지
않는다. MZ2AZ-415의 앱 구현은 PR #235로 main에 반영됐고, Apple 키·개발자 팀 서명·
실제 가입·재로그인·탈퇴 확인은 MZ2AZ-416과 함께 남아 있다.

광고 측정의 기본 비활성화와 기존 동의 조건은 유지한다. MZ2AZ-391·402·416의
콘솔 값·정책·서명·실기기 조건은 코드 검증과 구분해 기록한다. 유료 LLM·길찾기를
시험 호출하지 않는다.

## 되돌리기

각 기능은 관련 티켓 키를 가진 별도 커밋으로 남긴다. 앱 변경을 되돌려도 서버
계약과 기존 사용자 데이터는 유지된다. 기기 테마 값은 선택 항목이므로 구형 앱은
무시한다. 로컬 DB 조정 전 백업과 사용자 데이터 대조 결과를 보관한다.
