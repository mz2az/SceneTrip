# iOS 주변 POI 묶음 표시

- 티켓: [MZ2AZ-403](https://mz2az.atlassian.net/browse/MZ2AZ-403)
- 실행 승인: 2026-10-11 사용자가 백로그 보류를 해제했다.
- 범위: 코스 편집·여행 지도의 주변 편의시설. 촬영지·코스 번호 핀·가이드 추천 핀은 유지한다.

## 표시와 선택

현재 내려받고 분류·대표 촬영지·코스 필터를 통과한 POI만 묶는다. 화면 좌표로 환산한
64pt 반경 안의 점을 가까운 묶음에 넣으며 ID 순서로 처리해 결과가 재현된다. 고른 POI는
따로 표시하므로 확대·축소해도 카드의 대상이 다른 가게로 바뀌지 않는다. 새 API·유료 호출은 없다.

네이버 SDK의 `NMCBuilder`도 검토했다. 현재 받은 최대 30건에서 구성원 목록·고른 점 제외를
순수 값 테스트로 검증하기 위해 작은 공간 색인과 공통 렌더러를 사용한다. 위·경도는
Web Mercator로 환산하고 인접 셀도 찾아 셀 경계의 가까운 점이 서로 겹치지 않게 한다.
화면 회전·기울기와 무관한 지도 축척 기준이므로 실제 원근의 픽셀 거리를 뜻하지는 않는다.

묶음에는 개수가 보인다. 누르면 중심으로 두 단계 확대한다. 같은 좌표의 여러 POI 또는
최대 줌에서는 전체 구성원 목록을 열어 각각 선택할 수 있다. 목록에서 선택하면 기존
POI 카드·같은 촬영지 대표 카드·코스 담기 경로를 그대로 사용한다. 목록은 한국어·영어
표기와 큰 글자·VoiceOver를 지원한다.

## 받은 개수와 총수

묶음의 수는 현재 받은 POI의 수다. 목록에 이 범위를 명시한다. 기존 bbox 요청의 30건
제한·줌 13 미만에서 조회하지 않는 정책을 변경하지 않는다. 지역 전체 총수와 촬영지 전국
지도 건수는 MZ2AZ-372의 별도 범위다. 91만 POI를 한 번에 내려받거나 그리지 않는다.

## 검증

순수 값 단위 테스트로 줌에 따른 분리, 인접 셀, 같은 좌표 전체 구성원, 선택한 POI 제외,
ID 중복, 잘못된 좌표, 필터 결과별 수 보존, 입력 순서 독립성을 확인한다. `just check`를
통과한 뒤 PR의 CI 로그를 확인한다. 실제 지도·연속 조작의 화면 및 CPU 검증 여부는
최종 PR에 실제 수행한 내용으로 기록한다.
