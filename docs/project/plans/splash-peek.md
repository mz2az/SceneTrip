# 앱 시작 화면 — 해태가 글자를 잡고 빼꼼 (MZ2AZ-549, 2026-11-10)

앱을 켤 때 보이는 화면을 담백하게 바꾼다(사용자 요청). 시안: https://claude.ai/artifact/T3WBPosqMhpmjkpPPf3uJJ

## 움직임 (약 1.5초)

1. 흰 바탕 가운데 보라(`#5B49D6`) 「SceneTrip」 글자가 0.35초에 나타난다.
2. 앞발 둘이 글자 윗변에 올라와 걸친다(왼발 0.35초, 오른발 0.42초부터, 살짝 튕김).
3. 그 사이로 해태 머리가 글자 뒤에서 뿅 올라온다(0.72초부터). 머리는 글자 윗변에서 잘려, 글자 뒤에 있다가 올라오는 것처럼 보인다.
4. 아래 문구 「Stand where the scene happened」(1.1초), 0.55초 뒤 앱으로(0.25초 서서히).

- **켤 때(콜드 스타트)만.** 앞으로 올 때는 다시 안 보인다. 누르면 바로 넘어간다. 동작 줄이기면 움직이지 않고 0.7초.
- 자동 화면 점검·뒷문 실행은 `-skipSplash 1` 로 건너뛴다.
- iOS 는 MZ2AZ-526(첫 실행 덮개 걷기)에서 시작 화면이 빠져 있었다 — 이 화면만 다시 넣는다(언어 고르기·사용법은 그대로 없다).

## 그림 (사용자가 준 것)

- 얼굴 `splash-haetae-face` — 구름 갈기 해태 얼굴(앞발 없음, 1254px 원본의 투명 여백을 잘라 720px). 이전 얼굴은 앞발이 그려져 있어 따로 올라온 앞발과 겹쳤다.
- 앞발 `splash-paw-left`·`splash-paw-right` — 한 쌍 그림을 왼발·오른발로 나누고 사이 얼룩을 뺐다.
- 셋 다 알파 0.1 아래의 옅은 얼룩을 지웠다(테두리 가장자리는 남는다).

## 순서

iOS 먼저(시뮬레이터 확인) → 사용자 확인 → Android 의 지금 핀 낙하 시작 화면(`onboarding/SplashView.kt`)을 같은 것으로.
