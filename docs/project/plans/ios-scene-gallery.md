# iOS 장면 사진 여러 장 (MZ2AZ-430)

## 범위

서버 1.14.0의 `Scene.sceneImageUrls` 순서를 그대로 사용한다. 카드와 설명 시트는
첫 사진 및 장수 배지를 보여 주고, 확대 화면에서 이전·다음 버튼으로 모든 사진을 본다.
확대 이동과 페이지 넘기기 제스처가 충돌하지 않도록 페이지 전환은 버튼으로 제공한다.
한 장은 기존 표시, 빈 배열은 빈 영역이며 포스터·구형 단일 필드로 대체하지 않는다.

## 구현과 검증

- HTTP(S) 주소만 사용하며 배열 순서와 같은 URL의 반복도 유지한다.
- 사진 전환마다 독립된 페이지 상태를 만들고 확대 배율을 100%로 초기화한다.
  사라진 페이지의 다운로드는 취소 확인 뒤 화면 상태를 갱신한다.
- 이전·다음 버튼은 끝에서 비활성화하며 장수·현재 번호를 함께 보여 준다.
- 순서·빈 배열·잘못된 URL·단일 URL 우선순위 회귀 시험과 `just check`를 실행한다.
- 실제 송광사·새연교 2장, 단일 사진, 빈 사진을 시뮬레이터에서 확인한다.
  서버·데이터 미반영으로 못 본 항목은 완료로 기록하지 않는다.

Android와 서버 변경은 이 PR 범위 밖이다. 되돌리기는 이 PR을 revert한다.

## 검증 기록 (2026-10-14)

신규 배열 회귀 시험의 미구현 실패를 확인한 뒤 iOS 단위 시험 719개가 통과했다.
`just check`도 전체 122개 빌드 대상과 22개 테스트 대상을 통과했다.
배열 순서·반복 주소·빈 배열·잘못된 주소 제외와 기존 확대 규칙을 포함한다.
독립 코드 검토에서 페이지 전환 시 상태 초기화·취소된 다운로드의 응답 무시를 확인했다.

현재 로컬 송광사 상세에는 `sceneImageUrls` 필드 자체가 없어 최신 서버 적용이 먼저다.
Jira 429의 534행 CSV는 아직 공유 전으로 기록돼 있다. 실제 송광사·새연교 두 장,
작은 화면·큰 글자의 확대/페이지 버튼 배치는 후속 시뮬레이터 검증으로 남긴다.
이 기록은 실제 사진 E2E 또는 Android 완료를 뜻하지 않는다.
