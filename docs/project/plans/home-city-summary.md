# 홈 도시 줄 빠르게 — 도시 요약 창구와 고정 대표 사진

- **작성일**: 2026-11-09
- **티켓**: MZ2AZ-545
- **상태**: 진행 — 계획 확인(2026-11-09), 계약 1.26.0·백엔드 구현
- **앞선 문서**: MZ2AZ-531(홈 도시별 성지, 웹 `features/home/homeCities.ts`), [web-proto-apply.md](./web-proto-apply.md)

---

## 1. 왜

홈 맨 위 사진(「Where are you traveling?」)과 도시 칸(「Seoul 124」)이 시험용 웹 첫 방문에서 **15~23초** 뒤에 뜬다(2026-11-09 실측).

| 원인 | 실측 |
| --- | --- |
| 도시를 세려고 촬영지 목록 **전체**를 받는다 — DEV 476곳, 200개씩 3쪽, 앞 쪽이 와야 다음 쪽 | 쪽당 약 125KB |
| 같은 목록을 한국어(도시 열쇠용)·화면 언어(이름용)로 **두 번** 받는다 | 6번 요청 |
| 시험용 웹은 한국에서도 LA Cloudflare(`colo=LAX`)를 거친다 | 요청 하나 2~3초(API 직접 0.1초) |
| 사진 머리는 그 목록이 다 와야 사진을 고른다 | 원본 사진 장당 300~600KB |

화면이 실제로 필요한 것은 도시 이름·촬영지 수·대표 사진 한 장이다. 도시를 고른 뒤에야 그 도시의 촬영지 목록이 필요하다.

## 2. 바꾸는 모양

```
지금:    웹 → /places 476곳 × 2개 언어(차례로 6번) → 도시 세기 → 사진 고르기 → 사진
바꾼 뒤: 웹 → 고정 대표 사진(웹에 동봉) 바로
           └→ GET /places/cities 한 번 → 도시 칸·수
           └→ 도시를 고르면 GET /places?city=서울 한 번 → 그 도시 촬영지
```

### 2-1. 고정 대표 사진 (웹만)

- 사용자가 고른 사진(2026-11-09, 후보는 DEV 인기순 상위): 서울 뚝섬한강공원(186)·부산 감천문화마을(403)·경주 오릉(390)·인천 월미도(199)·
  제주 군산오름(295)·수원 화성행궁(410)·포항 호미곶해맞이광장(195)·대구 서문시장(140). 원본 217~645KB.
- 화면 폭에 맞게 줄여(가로 1080px 안팎, 장당 100KB 안팎) `apps/scenetrip-web/public/` 에 둔다. 사진 아래 문구(도시 · 촬영지 · 작품)도 함께 고정한다.
- 도시 칸·수는 창구가 오면 채운다. 사진은 창구를 기다리지 않는다.

### 2-2. 계약 (1.26.0 — 더하기만)

| 창구 | 하는 일 |
| --- | --- |
| `GET /places/cities` | 도시마다 `{ key, name, placeCount, center{latitude,longitude}, bbox }`. 순서는 고정 다섯(서울·부산·경주·인천·제주) → 촬영지 수 내림차순 → 열쇠 이름순. 0곳은 뺀다 |
| `GET /places?city=<key>` | 기존 목록에 도시 조건을 더한다. 다른 조건(q·bbox·contentId·정렬)과 함께 쓸 수 있다. 모르는 열쇠는 빈 목록 |

- `key` 는 언어와 무관한 한국어 열쇠(「서울」, 「경기 광주」) — 분석 `select_home_city.city` 값과 같다.
- `name` 은 `Accept-Language` 의 이름(영어면 「Seoul」, 시·군은 영어 주소의 `…-si` 를 뗀 것).
- `center`·`bbox` 는 웹의 「가까운 도시 고르기」와 「이 지역 지도」(`regionBbox`)에 쓴다.
- 숨긴 촬영지(`hidden_at`)는 세지 않는다 — `/places` 목록과 같은 모집단.

### 2-3. 도시 묶기 규칙을 서버로

지금 규칙은 웹 `features/home/homeCities.ts`(MZ2AZ-531)에 있다. 그대로 Java 로 옮긴다.

- 특별시·광역시·특별자치시·제주특별자치도 → 통째로 한 도시
- 도 → 그 아래 시·군. 이름이 겹치는 곳(광주·고성)은 도를 붙인다(「경기 광주」)
- 전남광주통합특별시 → 도처럼 시·군, 구로 시작하면 「광주」
- 한국어 주소는 `place_i18n(lang='ko')`, 영어 이름은 표(광역) 또는 그 도시 촬영지의 영어 주소

웹·서버 규칙이 갈라지지 않게, 웹 규칙 시험(`homeCities.test.ts`)의 사례를 서버 시험에도 옮긴다. 웹의 규칙 파일은 2단계에서 지운다.

### 2-4. 웹

1. 사진 머리: 고정 사진으로(2-1).
2. 도시 줄·홈 도시별 성지 카드(MZ2AZ-531): `/places/cities` 로 칩과 수, 고른 도시만 `/places?city=` 로.
3. 시안 도시 화면(촬영지 담기·자동 코스): 들어갈 때 `/places?city=` 로 받는다.
4. 옛 서버(창구 없음)면 지금 방식으로 돌아간다. 옛 서버는 `/places/cities` 의 `cities` 를 촬영지 번호로 읽다 실패해 404 가 아니라 **400** 을 준다(DEV·PRD 실측) — 404·400 둘 다 옛 서버로 본다 — PRD 배포 전까지 시험용 웹이 DEV 를 보므로 실제로는 쓰지 않지만 안전판.

## 3. 시험

| 갈래 | 무엇 |
| --- | --- |
| 단위 | 주소 → 도시 규칙(웹 사례 그대로), `city` 빈 값 400, 영어 이름 |
| 통합(실제 PostgreSQL) | 수·순서(고정 다섯 → 수), 숨긴 촬영지 제외, 영어 이름, `city` 조건이 q·bbox 와 함께 |
| 실제 요청 | `just update scene-api` 뒤 curl, DEV 배포 뒤 시험용 웹 첫 방문 사진까지 시간(지금 23초) |

## 4. 남는 것

- 시험용 웹이 LA Cloudflare 를 거치는 문제(요청마다 2~3초)는 이 일로 줄지 않는다 — 요청 수를 줄일 뿐이다. 웹이 API 를 직접 부를지(CORS)는 따로 정한다.
- iOS·Android 홈에 같은 도시 줄을 넣을 때 이 창구를 쓴다.
