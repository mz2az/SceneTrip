# 앱 움직임·작품 고르기·검색 서랍 맞추기 (2026-11-10, MZ2AZ-547)

안드로이드를 휴대폰에서 써 본 사용자가 찾은 것을 웹·iOS·안드로이드에 함께 반영한다.
움직임 기준은 웹 시안이고(`apps/scenetrip-web/src/features/proto/`, `proto.css`), 아래 「바꾸는 것」 셋은 웹도 함께 바꾼다.

## 1. 작품 고르기 단계(「누구의 장면을 따라갈까요?」)

- 처음 30개를 받고, 목록 끝에서 한 줄 안이 보이면 다음 30개(`GET /contents?limit=30&offset=…`)를 받는다. `total` 에 닿으면 멈춘다.
- 안내 글 아래 검색칸 「작품 이름으로 찾기」. 글자를 넣고 0.3초 멈추면 `GET /contents?q=…&limit=30`(다음 쪽도 같은 방식).
  비우면 원래 목록으로. 결과가 없으면 「「q」 에 맞는 작품이 없어요」.
- 고른 작품은 검색·쪽 넘김과 상관없이 유지한다 — 검색 결과에 없어도 고른 것은 남고, AI 일정 요청은 고른 작품의 제목을 쓴다.
  아무것도 안 고르면 지금처럼 인기 작품 앞 3개.
- 찜한 작품 먼저(이미 받은 것 안에서), 그다음 서버 순서. 찜 미리 고르기는 지금처럼 처음 한 번.
- 계약 변경 없음 — `/contents` 의 `q`·`offset` 은 이미 있다.

## 2. 지도 검색 결과 줄

- 줄 왼쪽 40×40 회색 칸과 그 안의 갈래 색 점을 뺀다. 이름·주소 글은 줄 왼쪽 여백(16)에서 시작하고, 구분선도 같은 들여쓰기.
- 입력 중 목록과 엔터 뒤 결과 서랍 둘 다(같은 줄 부품).

## 3. 검색 결과 서랍 끌기

- 손잡이와 서랍 머리를 위아래로 끌 수 있다. 손을 떼면 가까운 높이로 붙는다: 지도 높이의 **42%** 또는 **78%**.
  빠르게 튕기면(초당 약 600pt/dp 이상) 그 방향 높이로. 끄는 동안은 손가락을 따라가고, 42% 아래·78% 위로는 조금만 늘어난다.
- 손잡이를 누르면 지금처럼 42% ↔ 78%. 붙는 움직임은 0.28초.
- 목록이 맨 위일 때 아래로 끌면 서랍이 내려간다(iOS·안드로이드. 웹은 손잡이·머리만).
