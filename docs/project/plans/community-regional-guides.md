# 지역 성지 가이드와 기존 기기 후기 보존 (MZ2AZ-423)

2026-10-13 사용자가 기존 사진 후기 2개의 복구와 지역 안에서 이어지는 사진·코스
추천 가이드 20개를 요청했다. 앱·자료 준비 작업이며 서버 계약은 바꾸지 않는다.

## 보존과 화면

기존 기기 후기 2개는 `scenetrip.communityPosts`와 커뮤니티 사진 폴더에 남아 있다.
원문·첨부 코스·사진 5장을 백업했고 원본을 바꾸지 않는다. 서버 피드만 보이던
커뮤니티에서 기기 보관함도 찾을 수 있게 한다. 기기 글을 자동 공개 게시하거나
서버 계정으로 귀속시키지 않는다.

## 새 가이드

- 글쓴이는 별도 로컬 편집 계정 `씬트립가이드`이며 본문에 추천 가이드임을 적는다.
  직접 여행했다는 경험을 만들지 않는다.
- 서울 종로, 수원, 전주, 인천 원도심, 강릉, 부산, 포항, 제주 동부·서귀포,
  파주, 청주, 대구의 자료를 확인해 20개 테마를 구성한다. 한 글은 같은 시 안의
  인접 장소 3~5개다. 제주도도 성산·제주시 동부·서귀포 도심을 각각 나눈다.
- 촬영지와 쉬어 가는 일반 관광지를 구분한다. DB에 있는 실제 장소·편의시설
  ID와 좌표를 확인하고 도시·최대 거리·중복 장소를 검증한다.
- 각 글에 제목·새로 쓴 본문·방문 순서·체류 시간·교통 방식·짧게 줄이는 방법·
  방문 전 확인할 정보·참고 링크를 넣는다. 운영시간과 가격을 과거 기사에서
  현재 사실로 옮기지 않는다.
- 사진은 사용 유형을 확인한 한국관광공사 공공누리 제1유형으로 고른다. 사진의
  실제 장소와 원본 URL·출처·라이선스를 글과 자료에 남긴다. 블로그 사진은
  복사하지 않는다. 본문은 참고한 사실을 바탕으로 새로 쓴다.
- 글마다 사진 업로드 키를 새로 발급받고 `POST /uploads`·서명 PUT·`POST /posts`를
  사용한다. 게시 계정의 코스를 먼저 만든 뒤 공개 사본으로 붙인다. 읽는 사람은
  기존 `POST /posts/{id}/saves`로 자기 코스로 담는다.

## 로컬 적재와 검증

로컬 kind·localhost만 허용하는 준비 명령을 만든다. 자료를 검증한 뒤 별도 편집
계정과 코스·글을 넣고 생성 ID·사진 해시·원본 자료 해시를 로컬 상태 파일에 남긴다.
재실행은 완료한 글을 다시 만들지 않는다. 응답 유실은 내 글·코스에서 확인하고
자동으로 중복 요청하지 않는다. 되돌릴 때는 기록된 편집 계정의 자료만 대상으로
한다. 사용자 글·코스·로그인·원래 사진은 변경하지 않는다.

1. 지역을 벗어나는 좌표, 잘못된 장소 ID, 사진 출처 누락, 중복 글과 길이 경계를
   외부 서비스 없는 테스트로 확인한다.
2. 실제 로컬 API에서 20개 목록·전문·사진 읽기·코스 사본의 순서를 대조한다.
3. 별도 검증 회원으로 코스 하나를 담아 원본과 다른 ID·같은 장소/순서를 확인하고
   시험 코스만 정리한다.
4. iOS에서 원래 후기의 사진·본문·첨부 코스와 새 가이드의 목록·상세·사진을
   확인한다. `just check`와 PR CI를 확인하고 main에 반영한다.
5. iOS 작업이 끝나면 현재 열린 Android 업데이트 세션에 main SHA·티켓·화면
   동작·공유 자료 상태를 전달한다. 같은 가이드를 다시 적재하지 않도록 한다.

## 관련 작업

MZ2AZ-396의 기기 글 보존과 MZ2AZ-352의 코스 사본 계약을 따른다. MZ2AZ-406의
운영 사진 삭제·보관 정책, MZ2AZ-349의 실제 씬 사진 준비는 별도 조건이다. 유료
길찾기·LLM, AWS 배포·공유 DB 변경은 이 작업에 포함하지 않는다.

## 완료 근거

가이드 20개·사진 32장·코스 20개를 로컬에 적재하고 공개 API의 본문·사진 해시와
코스 사본을 검증했다. 별도 시험 회원의 담기를 확인한 뒤 시험 코스와 회원을 지웠다.
적재 직후 원래 12개 테이블의 행 수·해시가 같았고, 실제 기기의 옛 글 목록과
낙산 글 상세 및 SE의 공개 글·코스·로그인 안내를 확인했다. 가이드 20개 회귀·iOS
682개와 `just check` 전체 21개 검사 대상이 통과했다.

완료 범위와 옛 사진의 페이지 넘기기 등 실제 조작의 한계는
[검증 결과](../../qa/community-guides-verification.md)에 기록했다.
