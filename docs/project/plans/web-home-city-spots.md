# 웹 홈 「도시의 성지」 (MZ2AZ-531, DEV 실험)

- **상태**: 웹(`apps/scenetrip-web`)에만 구현, DEV 에서 확인. iOS·Android·서버·계약은 건드리지 않는다
- **결정(사용자, 2026-11-07)**: 아래 §2 가 그대로 사양이다
- **왜**: 광고로 들어온 사람은 대부분 첫 화면만 보고 나간다. 홈 첫 화면에서 바로 「이 도시에서 갈 수 있는 촬영지」를 보여 할 일을 알게 한다

## 1. 자리

홈 인사(`HomeHeader`) 바로 아래, 「내 여행 이어가기」 페이저 위.

```
해태가 기다렸어요 / 오늘은 어느 장면으로 갈까요?        ⚙
서울의 성지                              지도에서 124곳 보기 ›
[◎ 내 위치] [서울 124] [부산 19] [경주 6] [인천 20] [제주 28] [수원 16] …   ← 가로 스크롤
[사진│장소명│작품] [사진│장소명│작품] …                                    ← 가로 스크롤
(내 여행 이어가기 …)
```

## 2. 사양

| 항목 | 정한 것 |
| --- | --- |
| 제목 | 「%@의 성지」 / "Spots in %@" — 고른 도시 이름 |
| 카드 | 사진 · 장소명 · 작품 제목(목록 응답의 `contents[0]`). 카드마다 따로 부르지 않는다. 누르면 그 촬영지 상세(`router.openPlace`, 「오늘의 성지」와 같은 길) — `view_place` 는 상세가 열리면서 이미 보낸다 |
| 링크 | 「지도에서 N곳 보기 ›」 / "See all N on map ›" — 작품검색 탭으로 가서 그 도시 촬영지를 감싼 범위로 「현 지도 내 성지 검색」을 걸고 결과에 카메라를 맞춘다(§4) |
| 도시 단위 | 한국어 주소의 첫 낱말. 특별시·광역시·특별자치시·제주특별자치도는 통째로 한 도시(서울·부산·인천·대구·대전·울산·광주·세종·제주). 도(경기도·경상북도·강원특별자치도·전북특별자치도 …)는 그 아래 시·군(수원·경주·파주 …) |
| 순서 | 고정 다섯 = 서울 · 부산 · 경주 · 인천 · 제주(이 순서), 그다음 나머지를 촬영지 수 내림차순, 같으면 이름순. 0곳인 도시는 숨긴다(고정 다섯도) |
| 처음 고르는 도시 | 위치 권한이 **이미** 허용돼 있고(Permissions API `geolocation` = `granted`) 앱의 위치기반서비스 동의도 돼 있으며 위치가 금방(캐시 허용, 3초) 오면, 한국 안일 때 가장 가까운 도시(그 도시의 가장 가까운 촬영지까지 거리로 견준다). 아니면(묻지 않음·거부·한국 밖·시간 초과) 서울. **처음 화면에서는 권한을 묻지 않는다** |
| 「내 위치」 칩 | 줄의 맨 앞. 누를 때만 위치를 묻는다(앱의 위치 동의 시트 → 브라우저 권한). 실패·한국 밖이면 지금 도시를 그대로 두고 한 줄 안내 |
| 가볍게 | 새 의존성 없음. 360px 폭에서 페이지 가로 스크롤 없음(칩·카드 줄만 스크롤) |
| 분석 | `select_home_city`(`city`, `source` = `default`·`chip`·`near_me`) — 웹 전용 실험 이벤트. 카드에서 상세를 열면 기존 `view_place` |

## 3. 도시 열쇠를 어디서 얻나 (결정)

목록 응답(`PlaceSummary`)에는 지역 코드가 없고 **앱 언어로 번역된 주소**만 있다(`en` 이면 `…, Gyeongju-si, Gyeongsangbuk-do`).
영어 주소를 한국어 도시로 되돌리려면 전국 시·군 로마자 표가 필요하다. 그래서:

- **열쇠는 언제나 한국어 목록에서 얻는다.** `GET /places?limit=200` 을 `Accept-Language: ko` 로 끝까지(DEV 476곳 = 3번) 받아 주소 첫 낱말로 도시를 정한다. 촬영지 수·좌표도 여기서 센다.
- 앱 언어가 `en` 이면 같은 목록을 `en` 으로도 받아 **id 로 맞춰** 카드의 이름·작품 제목·사진을 그 언어로 그린다. 도시 이름(영어)은 광역 도시 9곳은 표, 시·군은 그 도시 촬영지의 영어 주소에서 `…-si`·`…-gun` 을 떼어 쓴다(없으면 한국어 이름).
- 한 세션에 한 번만 받는다(언어별로 기억). 언어를 바꾸면 영어 쪽만 다시 받는다.
- 이를 위해 API 창구(`src/api/client.ts`)가 호출부가 직접 준 `Accept-Language` 를 덮어쓰지 않게 했다(주지 않으면 지금처럼 앱 언어).
- 열쇠 이름이 겹치는 곳: 경기도 광주시는 「경기 광주」(광주광역시와 구별), 고성군은 「강원 고성」·「경남 고성」.
- 전남광주통합특별시(2026 통합, DEV 24곳)는 통째로 하나가 아니라 도처럼 시·군으로 나눈다 — 구(동구 등)로 시작하면 옛 광주광역시 자리라 「광주」.

`select_home_city.city` 는 이 한국어 열쇠다(언어와 무관하게 같은 값).

## 4. 「지도에서 보기」

탭 사이 쪽지(`pendingStore`)에 `region`(그 도시 촬영지를 감싼 bbox, 가장자리에 약간 여백)을 남기고 작품검색 탭으로 간다. 작품검색 탭은 쪽지를 읽어
기존 「현 지도 내 성지 검색」(`searchInViewport`, 목록 위 「이 지도에서 N곳 · 해제」)을 그 bbox 로 걸고, 결과가 오면 카메라를 결과 핀에 맞춘다(`fitToken`).
bbox 는 네모라 도시 경계 밖 촬영지가 조금 섞일 수 있다(서울 bbox 에 경기 몇 곳) — 개수는 지도 쪽 결과가 기준이다.

## 6. 남은 것

- iOS·Android 에는 없다. 실험 결과를 보고 옮길지 정한다.
