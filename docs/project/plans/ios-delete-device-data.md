# 이 기기의 기록 지우기 (MZ2AZ-471)

## 범위와 계약 선행 조건

iOS 마이페이지의 비회원 전용 기능이다. 가입자는 기존 회원 탈퇴를 사용한다.
scene-api 1.22.0의 생성 `deleteMe(xInstallId:)` 요청을 토큰 없이 보내며 설치 UUID는 유지한다.
작업 시작 시 이 작업 트리의 계약은 1.21.0이고 해당 인자가 없다. 계약·서버는 이 변경에서
수정하지 않으며 1.22.0 반영과 생성 클라이언트 확인이 선행되어야 한다.

## 구현 순서

1. 작은 요청 타입에 생성 요청과 결과 매핑을 모으고 204·401 SESSION_REQUIRED·실패 시험을 작성한다.
2. 비회원만 삭제 행을 보이며 확인 후 실행한다. 실행 중 중복 삭제·로그인을 막는다.
3. 204에서만 로컬 사본을 비우고 기존 계정 변경 알림을 보낸다. 로그아웃·탈퇴도 같은 사본
   초기화를 사용한다. 삭제 전 조회의 늦은 응답이 사본을 되살리지 않게 세대를 확인한다.
4. 장바구니 행·저장 아이콘, 코스·방문 스탬프, 찜 ID·요약·기기 사본을 비운다.
   기존 탈퇴와 같이 `FootprintStore.forgetOwner()`로 발자취와 기록 동의·지도 표시도 초기화한다.
   설치 UUID·로그인 토큰·통계 설정·AI 동의는 건드리지 않는다.
5. SESSION_REQUIRED는 로그인 후 회원 탈퇴를 안내한다. 네트워크·서버 오류는 데이터를 보존한다.
   한국어·영어 문구와 앱 README를 갱신한다.

## 검증

- 단위 시험: 요청 메서드·경로·설치 헤더·토큰 미포함, 204 성공 시에만 초기화,
  SESSION_REQUIRED 분류, 네트워크·5xx 실패 보존, 가입자 행 숨김·실행 거절, 중복 실행 차단.
- 수동 확인: 비회원 데이터 준비 → 취소 시 보존 → 삭제 성공 후 마이페이지·홈·검색·코스가
  비어 있음 → 설치 UUID 동일 → 다음 저장 정상. 가입자는 회원 탈퇴만 표시.
- 사용자 요청에 따라 네트워크·Bazel·just·빌드·테스트 실행과 커밋은 하지 않는다.
  SwiftFormat은 변경한 Swift 파일에만 적용한다. `just check`는 사용자가 실행한다.
