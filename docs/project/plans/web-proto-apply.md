## 1. 무엇을 하는가

시안으로 만든 화면을 **시안 장치 없이 실제 화면으로** 바꾼다. 시안은 원래 화면 옆에 `protoAvailable && proto !== null` 갈래로 붙어 있다.
적용은 그 갈래를 원래 화면 자리에 올리고 원래 화면·갈래·시안 스위치를 걷어내는 일이다.

서버가 없는 기능(아래 §3 의 ❌)은 **이 브라우저에만 저장하는 껍데기**다. 적용할 때 서버가 준비되지 않았으면 그 부분은 **숨기고** 낸다 — 껍데기를
실제 앱에 내면 사용자가 쓴 댓글·좋아요가 다른 사람에게 안 보이고 기기를 바꾸면 사라진다.
