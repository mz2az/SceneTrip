# 웹 「어디로 가세요?」 시안 비교 — 로컬에서만 보는 껍데기

- **상태**: 시안 만드는 중(2026-11-07). 로컬(`just web-dev`)에서만 비교한다. 고른 안만 다듬어 dev → main 으로 낸다
- **왜**: 광고로 온 사람의 대부분이 첫 화면만 보고 나간다. 1주차 광고에서 「Coming to Korea this week?」 소재만 앱 안 행동 3.8%(다른 소재 0.3%·1.5%)
  — 이미 여행을 정한 사람에게는 「어떤 드라마?」 보다 **「어디로 가세요?」** 가 먼저다. 앱의 주된 길을 도시 → 추천 촬영지 → 코스(자유 수정)로 바꾸는 안을 비교한다
- **기반**: `dev` 브랜치(main + 웹 실험 #416 도시별 성지·#417·#418). 도시 묶기는 #416 의 `homeCities.ts`·`homeCityModel.ts` 를 그대로 쓴다

## 1. 바꿔 보는 법

`just web-dev` → `http://localhost:5173/?proto=a` (`b`·`c`, 끄기 `off`). 고른 값은 탭을 닫을 때까지 남는다(sessionStorage).
화면 오른쪽 아래 「시안」 단추로 바꾸고 「처음부터」 로 시안의 저장값(고른 도시·여행)을 지운다. **값을 주지 않으면 지금 화면 그대로다.**

## 2. 시안

| 시안 | 첫 화면 | 그다음 |
| --- | --- | --- |
| A 질문 카드 | 지금 홈 맨 위에 「어디로 여행 가세요?」 + 도시 칩 | 도시 → 추천 촬영지 목록(담기) → 「N곳으로 코스 만들기」(며칠) → 코스 편집 |
| B 질문 먼저 | 처음 들어오면 전체 화면: 「어디로?」 → 「며칠?」 | 추천 촬영지 목록(담기) → 코스 만들기 → 코스 편집. **두 번째부터**는 질문 대신 홈 맨 위 「부산 여행 · 2일」 카드(담은 곳·코스 상태 · 다른 여행 · 도시 바꾸기) |
| C 바로 추천 코스 | B 처럼 「어디로?」 → 「며칠?」 → 「얼마나 빡빡하게?」 | 곧바로 완성된 코스 초안(껍데기) → 빼기·다른 곳으로 바꾸기·순서 바꾸기 → 저장 → 코스 편집. 두 번째부터는 B 와 같은 여행 카드 |

## 3. 진짜와 껍데기

| 무엇 | 어디서 |
| --- | --- |
| 도시·추천 촬영지 | 진짜 — `GET /places` 전부를 한국어 주소로 도시별로 묶은 것(#416), 인기도 순 |
| 담기 | 진짜 — `POST /cart/items` (DEV 서버) |
| 코스 저장·편집 | 진짜 — `POST /courses` + `PUT /courses/{id}` 후 기존 코스 편집 화면 |
| **도시·며칠·속도 → 코스 초안** | **껍데기** — 서버에 없다(`/guide/plan` 은 작품 이름이 필수). `features/proto/mockPlan.ts` 가 그 도시 촬영지를 가까운 순으로 이어 하루 3·5·7곳씩 나눈다. 고르면 서버 창구를 따로 설계한다 |
| 여행(도시·며칠) 기억 | 껍데기 — 이 브라우저의 localStorage. 고르면 서버(계정) 저장을 설계한다 |

## 4. 하지 않는 것(시안 단계)

- 시험·문구 번역·분석 이벤트 — 고른 안을 다듬을 때 시험을 먼저 쓰고 넣는다. 시안 코드는 main 에 들어가지 않는다
- iOS — 웹에서 고른 뒤 옮긴다
