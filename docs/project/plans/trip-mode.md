# 여행 모드 — 코스 시작부터 스탬프까지 한 흐름, 그리고 발자취 (iOS)

> 2026-09-02 사용자 제안. 지금의 길찾기는 **정지점마다 사람이 「길찾기」를 눌러야** 하고,
> 도착해도 다음 성지로 넘어가지 않는다. 계획용 핀 찍기(동선 최적화)까지는 맞으니 거기서
> 「코스 시작」을 누르면 그다음은 앱이 이어 가게 한다. 젤다 야생의 숨결의 「영걸의 길」
> (마지막 200시간의 이동을 지도에 남겨 되감는 기능)처럼 **발자취**도 남긴다.

## 1. 지금은 어떻게 도나

| 자리 | 지금 |
| --- | --- |
| `RouteEditorView` 「코스 시작」 | 서버 상태만 `active` 로 바꾼다. 화면은 그대로다 |
| 정지점 행 「길찾기」 | `RouteNavView(stop:dayStops:courseId:)` — **한 정지점**으로 가는 경로 하나 |
| `RouteLocator` | 위치를 **한 번만** 받고 끊는다(배터리). 정확도 100 m |
| 도착 | 그 한 번의 위치가 목적지 100 m 안이면 `visitedAt` 을 서버에 찍고 「스탬프 찍힘」 배너. 아니면 「여기 도착함」 단추를 사람이 누른다 |
| 다음 정지점 | 없다 — 화면을 닫고 편집 화면에서 다음 행의 「길찾기」를 누른다 |

즉 도착 감지는 사실상 화면을 연 순간 한 번뿐이고, 흐름을 잇는 주체가 사람이다.

## 2. 바꾸는 것 — 1단계 (앱을 켜 둔 상태, 이번 작업)

```
[코스 시작] ─→ 오늘 일차의 첫 미방문 정지점으로 길찾기 (현재 위치 → 1번)
                │
                ├─ 위치를 계속 받는다 (앱 사용 중, 25 m 간격)
                ├─ 반경 100 m 안에 든 채로 N분 머무르면 「도착」
                │     → 발바닥 스탬프가 화면 가운데 쾅 (햅틱) → visitedAt
                │     → 1.5초 뒤 「다음 성지: 2번」 으로 목적지가 저절로 바뀌고 경로를 다시 받는다
                ├─ 「여기 도착함」 단추는 남긴다 — 머무를 시간이 없거나 GPS 가 튈 때의 탈출구
                └─ 오늘 일차를 다 돌면 「오늘 일정 완료」
```

| 항목 | 값 | 이유 |
| --- | --- | --- |
| 도착 반경 | 100 m | 지금 값. 촬영지 좌표가 건물 한가운데가 아닐 수 있다 |
| 머무름(dwell) | **5분**(`TripMode.dwell`) — 개발 빌드 `-tripDwellSeconds 10` 뒷문 | 사용자 제안. 지나가기만 하는 것과 들른 것을 가른다 |
| 위치 갱신 | 100 m 정확도, 25 m 이동마다 | 내비가 아니라 미터 단위가 필요 없다 |
| 다음 정지점 | 같은 일차에서 **아직 방문 안 한** 첫 정지점(서버 `visitedAt` + 이 세션에서 찍은 것) | 순서대로 |
| 권한 | 「앱 사용 중」 그대로 | 「항상」 은 2단계 |

**스탬프 그림은 발바닥이다.** 지도 점에서 걷어낸 그 모양(2026-09-02)을 여기서 살린다 —
「해태가 밟고 간 자리」라는 원래 뜻과 맞고, 화면 가운데 찍히는 연출은 원보다 발바닥이
낫다. `PawStamp` (SwiftUI Shape, 큰 패드 + 발가락 셋).

### 발자취 — 1단계 범위

- 여행 모드(길찾기 화면)가 켜져 있는 동안 **토글이 켜져 있으면** 위치를 기록한다:
  `(lat, lng, time)`, 25 m 이동마다 한 점. 기기 파일(Application Support, JSON)에만 남는다 —
  서버로 보내지 않는다.
- **한국 안에서만** 기록한다(`KoreaBounds`). 밖에서는 토글이 켜져 있어도 점이 안 쌓인다.
- 길찾기 지도에 **연보라 점선**으로 그린다. 시간 되감기(슬라이더)는 2단계.
- 마이페이지에 「발자취 지우기」. 지우면 끝이다 — 복구 없음.

## 3. 2단계 (다음 작업, 이 문서에 덧붙인다)

- **지오펜스(`CLCircularRegion`) + 로컬 알림** — 앱이 뒤로 가거나 꺼져도 OS 가 「반경에 들었다/
  나갔다」로 깨운다. 배터리를 거의 안 쓴다. 앱당 20개 한도라 **다음 정지점 몇 개만** 건다.
  머무름은 진입·이탈 시각 차로 센다.
- **위치 권한 「항상」** — 스토어 심사에 사유 문구(`NSLocationAlwaysAndWhenInUseUsageDescription`)와
  실제 쓰는 이유가 필요하다. 팀 결정.
- 발자취 **시간 되감기** 슬라이더, 마이페이지 스탬프첩 옆 「발자취 보기」.
- `CLLocationManager.startMonitoringVisits()`(Apple Visits API) 검토 — 도착·출발을 OS 가
  묶어 주므로 머무름 판정과 발자취 둘 다에 배터리 없이 쓸 수 있다.

## 4. 구조

```
RouteLocator          한 번 받기(locate) + 계속 받기(track) 두 모드. track 은 화면이 닫히면 멈춘다
RouteNavView          목적지가 @State 다 — 도착하면 다음 정지점으로 바뀐다
 ├ RouteNavControls   머무름 판정(TripArrival) · 스탬프 · 다음 정지점
 ├ PawStamp           발바닥 스탬프 연출
 └ RouteNavMapView    발자취 점선 하나 더 그린다
FootprintStore        기록·저장·지우기. KoreaBounds 로 거른다
RouteStop.visited     서버 visitedAt 을 브리지가 옮겨 준다 — 「다음 미방문」 계산의 근거
RouteEditorView       「코스 시작」 → 바로 길찾기 화면
```

## 5. 검토한 대안

| 선택지 | 채택하지 않은 이유 |
| --- | --- |
| 반경에 **들기만 하면** 도착 | 버스로 지나가도 찍힌다. 머무름이 있어야 「갔다」가 된다(사용자 제안) |
| 바로 지오펜스로 | 권한 「항상」과 심사 사유가 먼저다. 1단계로 흐름이 맞는지 보고 간다 |
| 발자취를 서버에 | 이동 기록은 가장 민감한 데이터다. 기기에만 두고, 지우기를 쉽게 |
| 연속 GPS(최고 정확도) | 배터리. 25 m·100 m 로도 발자취와 도착 판정에 충분하다 |

## 6. 완료 조건 (1단계)

- 「코스 시작」을 누르면 길찾기 화면이 첫 미방문 정지점으로 열린다.
- 시뮬레이터에서 위치를 목적지 반경 안으로 옮기고(`xcrun simctl location`) 머무름 시간이
  지나면 발바닥 스탬프가 찍히고 다음 정지점으로 바뀐다.
- 발자취 토글을 켜면 이동한 자리가 점선으로 남고, 한국 밖 좌표는 기록되지 않는다.
- `just check`(Android 제외) 초록.

## 7. 데모 주행 — 중간발표 영상용 (2026-09-02 추가)

영상에는 「걸어가는 GPS」가 필요한데 시뮬레이터도 실기기도 그것을 찍을 방법이 없다
(`simctl location` 은 점 하나씩만 옮긴다). 그래서 **앱 안에 가상 GPS** 를 둔다 — 실행 인자
`-demoDrive N` 이 켜지면 길찾기 화면이 위치 서비스 대신 `DemoDrive` 가 내는 좌표를 받는다.

- **데모 코스는 저장소에 있다** — `apps/scenetrip-ios/resources/demo/demo-course.json`(정승길
  설치본의 「도깨비 외 1 2박 3일」, 3일차 15곳, 장소 id 는 `seed/v6.csv`). `-demoCourse 1` 이면
  경로여정이 뜰 때 같은 제목의 코스가 없으면 이 파일로 서버에 만들고, 그 코스를 연다. 팀원
  누구의 맥에서도 같은 영상이 나온다.
- **움직임**: 지금 목적지까지의 경로선(카카오 길찾기 `legs.path`)을 따라 초당 `speed` m
  (기본 12 m/s — 도보의 열 배, 영상 길이 때문)씩 0.4초마다 한 점. 경로선이 없으면 직선.
- **도착**: 실제 규칙과 같다 — 반경 100 m 안에 머무름(`-tripDwellSeconds 5`)이 차면 스탬프.
  주행은 반경 30 m 안에 들면 멈추고 스탬프·다음 성지 전환을 기다린 뒤 다시 움직인다.
- **어디까지**: `-demoDrive 3` 이면 3번 성지에서 멈춘다(영상은 1→3까지가 적당하다는 사용자 결정).
- **핀 위의 스탬프**: 방문한 정지점의 번호 핀 자리에 발바닥 배지가 얹힌다(`RouteNavMapView`
  `visitedStopIds`) — 영상에서 「찍혔다」가 지도 위에 남아야 한다.
- 켜는 법: `just ios-demo [until] [dwell]`. 앱 코드에서는 `DemoDrive.isOn` 이 아니면 아무
  것도 하지 않는다 — 실제 사용자에게는 존재하지 않는 기능이다.
