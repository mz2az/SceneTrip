# iOS 미완료 티켓 후속 검증과 출시 준비

- 상태: 구현·자동 검증 완료, PR CI 반영 예정. 실제 계정/기기·선행 계약 조건은 계속 추적
- 기준: main e739948, 2026-10-14 지라 미완료 69건·정승길 담당 28건과 댓글 91개 조회
- 스토리: MZ2AZ-148. 관련: MZ2AZ-363·366·428·431·416
- 사용자 요청: 남은 지라의 iOS 수정·검증을 진행하고 CI 확인 뒤 PR/main 및 로컬 앱에 반영한다.

## 먼저 수정할 결함

1. 토큰 갱신 요청 뒤 계정이 바뀌면 이전 계정의 성공·401 응답을 새 계정에 적용하지 않는다.
   `AuthRefresher`의 동시 갱신 공유도 같은 세션에만 한정한다(MZ2AZ-363·366).
2. 블로그 본문 사진의 서명 URL이 만료되면 실패 재시도 전에 원래 글 상세를 다시 받아
   같은 사진 키의 새 URL을 사용한다. 계정 전환·닫기 이후의 응답은 버린다(MZ2AZ-428).
3. 리뷰 행·내 리뷰에서 연 사진도 같은 리뷰를 다시 읽어 만료 주소를 갱신한다.
   기존 `PhotoGallery`의 갱신 구현을 재사용하며 무한 재시도를 추가하지 않는다(MZ2AZ-363).
4. 리뷰 작성/삭제는 초안을 연 계정의 세대가 유지될 때만 가능하고 계정이 떠나면 업로드를 취소한다.
   리뷰 목록의 첫 쪽/다음 쪽도 계정·정렬·요청 세대를 검사한다(MZ2AZ-363).
5. 닉네임 저장 뒤 도착한 같은 계정의 옛 프로필 조회가 새 닉네임을 덮지 못하게 한다(MZ2AZ-363·431).

각 결함은 지연 응답·계정 전환 또는 만료 주소를 재현하는 실패 시험부터 추가한다.
코드와 화면에서 확인한 결과를 구분한다. 생성 API 클라이언트와 현재 계약을 사용한다.

## 출시용 앱 준비

- MZ2AZ-416의 영어·한국어 위치 권한 문구와 앱의 required-reason API 매니페스트를 준비한다.
  SDK별 매니페스트와 앱 자체 선언을 구분하고 실제 번들에 포함되는지 검사한다.
- 시뮬레이터의 기존 키체인 그룹은 유지한다. 실기기용 서명 권한 자료를 따로 준비해
  유료 개발자 팀의 프로파일과 맞추는 절차를 문서화한다.
- 개발자 계정·프로파일·App Store Connect·PRD 서버·처리방침이 필요한 제출 단계는
  코드 준비와 구분해 남긴다. 실제로 제출하지 않은 앱을 제출 완료라고 기록하지 않는다.
- ATT/메타는 현재 정책과 기본 비활성화를 유지한다. 앱 등록은 권호의 391 댓글상 완료이며,
  숫자 App Store ID·Android 등록·수신 확인·정책 결정은 별도다.

## 실제 iOS 확인

- 기존 사용자 iPhone 17 대신 별도 SceneTrip Apple QA 기기를 사용한다.
- 홈 작품 가로 선반의 실제 드래그·복귀, 포스터 상세 이동, 프로필·닉네임·테마·큰 글자,
  사진 읽기·전체 화면·재시도·블로그 작성/미리보기 동선을 확인한다.
- 시험 계정을 쓰는 검증은 실제 Google/Apple 가입 검증과 구분한다. 시험 행만 추가·정리한다.
- 관찰하지 못한 기능은 그 이유와 선행 조건을 기록하고 티켓을 임의로 완료하지 않는다.
