# 로컬 SQL 파일 실행 (MZ2AZ-384)

## 구현·검증 계획

대형 SQL을 명령 인자에 넣으면 macOS 인자 길이 제한에 걸린다. 파일을
`kubectl exec -i`의 표준입력으로 보내는 `just db-psql-file <파일>`을 추가한다.
기존 `db-psql`의 직접 접속 경로는 유지하고, 새 명령은 로컬 kind 전용으로 제한한다.

1. 가짜 kubectl을 사용하는 Bazel 단위 테스트로 큰 파일·공백 경로·입력 오류·원격 차단·실패 전파를 먼저 검증한다.
2. 읽을 수 있는 일반 파일 하나만 허용하고 `require_kind_context` 뒤에 psql을 실행한다.
3. `ON_ERROR_STOP=1`로 SQL 오류에서 중단하고 `just check`로 전체 게이트를 확인한다.

## 사용·복구

`just db-psql-file "data/load images.sql"`처럼 파일 경로 하나를 준다.
`SCENETRIP_DB_HOST`가 설정되면 직접 접속 대신 실행을 거부한다. 대상 kind 컨텍스트와
네임스페이스는 기존 공용 헬퍼를 따른다. SQL 본문과 비밀번호는 출력하지 않는다.

이 명령은 SQL을 해석하거나 자동 트랜잭션으로 감싸지 않는다. 여러 문장을 실행하다
오류가 나면 앞서 커밋된 변경은 남을 수 있으므로, 적재 파일에 필요한 트랜잭션과
되돌리기 SQL을 준비한다. 실제 적재 전에 대상 DB의 기존 데이터와 행 수를 기록한다.
