# ADR 0014: POI(편의시설) 출처는 공공데이터다 — 티맵을 쓰지 않는다

> [0011](./0011-naver-place-unofficial-for-demo.md) 의 배경(「우리 자료(TMAP 수집)에는 사진·평점이
> 없다」)을 보정한다. 결정은 그대로다 — 카드는 여전히 네이버가 채운다. 자료가 공공데이터로 바뀌어도
> 사진·평점·영업시간이 없는 것은 같고, 전화번호까지 없어졌다.

## 배경

편의시설 47만 행은 TMAP 을 긁어 모은 것이었다(2026-08, 정승길). 약관상 공개 배포가 안 되고,
`verified`(공공데이터 대조) 같은 파생 칸이 판마다 바뀌었다. 2026-09-05 팀이 티맵을 쓰지 않기로
했고, 승길이 공공데이터로 다시 만들었다(`SceneTrip_POI_20260907`, 2026-09-07 판).

| 갈래 | 출처 | 행 |
| --- | --- | --- |
| 음식·숙박 | 소상공인시장진흥공단 상가(상권)정보 2026-06 | 840,255 · 80,483 |
| 관광 (+ 음식·숙박 일부) | 한국관광공사 TourAPI 국문 목록 | 33,285 (+13,495 · 2,939) |
| 교통 | 공항·철도역·도시철도·TAGO 터미널 정류소·환승센터 표준데이터 | 2,495 |

열두 키 모양은 TMAP 판과 같게 만들어져 적재 SQL 이 읽는 칸은 안 바뀐다. 실제 제약 셋 —
같은 가게가 상가정보와 관광공사 양쪽에 좌표가 몇 m 어긋나 들어 있다(음식 13,495 중 10,291),
상가정보는 인허가 기록이라 같은 가게가 여러 줄이다(음식 9,476 그룹), 상가정보에는 전화번호가 없다.

## 결정

우리는 **편의시설의 출처를 공공데이터로 하고 TMAP 자료를 지운다.** 적재 규칙 셋을 더한다 —
좌표가 한국 밖이면 버린다, 관광공사 음식·숙박은 같은 갈래의 상가정보 행이 100 m 안에 있고
이름이 포함 관계면 넣지 않는다(상가정보에 없는 것만 보탠다), 출처 교체는 `--prune` 으로
이번 입력에 없는 행을 지운다. 갈래는 food·stay·sight·transit 넷 그대로다. 외국어 이름은
지금 읽지 않는다.

## 검토한 대안

| 선택지 | 채택하지 않은 이유 |
| --- | --- |
| TMAP 을 계속 쓴다 | 약관상 공개 배포가 안 된다. 파생 칸이 판마다 바뀌어 적재 규칙이 흔들렸다. 팀 결정(2026-09-05) |
| 관광공사 음식·숙박을 다 넣는다 | 같은 가게에 핀이 둘 선다 — 10,291 곳 |
| 관광공사 음식·숙박을 다 뺀다 | 상가정보에 없는 3,394 · 1,363 곳을 잃는다. 관광공사에만 영문·일문 이름과 상세가 있다 |
| 상가정보의 층까지 키에 넣어 중복을 덜 접는다 | 같은 건물 다른 층의 같은 상호는 드물다. 문제가 보이면 그때 |
| 외국어 이름을 지금 넣는다 | 마이그레이션·`PoiStore`·계약이 든다. 다국어 표시가 필요해질 때(2026-09-09 결정) |

## 결과

**좋아지는 것**

- 공개 배포 가능한 자료다. 저장소 표본에 실제 행을 둘 수 있다.
- 행이 두 배(948,858)다. 상가정보가 전국 음식·숙박을 빠짐없이 든다.
- 관광공사 `src` 에 영문·일문 이름과 상세가 붙어 온다 — 나중에 읽으면 된다.

**나빠지는 것 / 감수하는 비용**

- 음식·숙박의 전화번호가 전부 없다. 카드의 전화는 네이버가 채울 때만 보인다.
- 종교 갈래(사찰·교회 12,027)가 사라진다. 관광공사 관광지에 유명 사찰은 있다.
- 주소 형식이 섞인다(상가정보는 동까지, 관광공사는 도로명 전체). 계약 설명을 그에 맞췄다.
- 상가정보는 시점·업종별 중복이 많아 1 m 규칙이 접는 양이 크다(12,353). 층이 다른 같은 상호는
  접힌다.
- 네이버 카드 표(`poi_naver`)가 CASCADE 로 비었다. 누를 때 다시 채워진다.

**후속 작업**

- 외국어 이름 — `poi.name_en`·`name_ja` 와 `Accept-Language` 폴백. 다국어 표시가 필요해질 때.
- 관광공사 상세(영업시간·사진)가 다 모이면 카드의 출처로 검토 — 0011 의 대체 후보.
- 서울 시내버스 정류장은 TAGO 에 없다. 필요해지면 서울 자체 자료.

## 검증

- `just seed-poi --prune` 뒤 `source_id ~ '^[0-9]+$'`(TMAP) 가 0 행, 갈래가 넷뿐이다.
- 표본 27 행의 통합 시험 — 겹치는 관광공사 행은 없고 안 겹치는 것은 있고 좌표 뒤바뀐 행은 없다.
- `just poi-smoke` 통과(2026-09-09, 강남 2 km `total` 3,395).
- 다시 볼 시점: 지도에 같은 가게 핀이 둘 보이면 100 m·이름 규칙을, 다른 가게가 하나로 접혔으면 층
  키를 검토한다.
