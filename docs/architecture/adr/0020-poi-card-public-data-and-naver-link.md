# ADR 0020: 편의시설 카드는 우리 공공데이터와 네이버 지도 링크로 — 비공식 호출을 내린다

## 배경

[0011](./0011-naver-place-unofficial-for-demo.md) 은 편의시설 카드의 사진·영업시간·평점을 네이버 지도 웹이 쓰는 내부
주소를 그 페이지인 척 불러 채우기로 했다 — **데모 한정, 스토어 제출 전에 대체**. 10 월 베타(20~30 명)도 외부 배포라 그 전에
내려야 한다(MZ2AZ-355, 정승길 요청 2026-10-05).

그 사이 대체할 것이 생겼다. 편의시설은 공공데이터 91 만 곳에 공식 영문 주소·로마자 읽기·분류 영어가 붙었고(MZ2AZ-358),
사진·별점은 **우리 리뷰**에서 온다(MZ2AZ-362 — 상세의 `rating`·`photos`). 앱은 이미 카드 창구를 부르지 않는다
(MZ2AZ-354 — iOS·Android 모두 `GET /pois/{id}` 로 그리고 네이버 지도로 넘긴다, 2026-10-08 코드 확인).

## 결정

우리는 네이버에서 **아무것도 가져오지 않는다.** 카드는 우리 자료(공공데이터 + 우리 리뷰)로 그리고, 더 볼 것은 네이버 지도로
**넘긴다**(링크).

- 비공식 호출 스위치 `scenetrip.naver.enabled` 를 모든 환경에서 끈다(기본값도 false).
- 이미 모은 `poi_naver` 행을 지운다(V23). 꺼도 카드 창구가 표에 남은 행은 그대로 내주기 때문이다. 백업은 저장소 밖 CSV 하나
  (`just poi-naver-backup`, 2026-10-04)뿐이고 서비스에 다시 쓰지 않는다.
- 카드 창구 `GET /pois/{poiId}/card` · `GET /pois/cards` 는 계약에 **deprecated** 로 표시한다. 꺼진 채로 남겨 두고(늘 「못
  찾음」), 코드(`poi/naver/`)와 함께 다음에 지운다 — 지우는 것은 파괴적 변경이라 계약 규칙(메이저 버전)을 따로 정해야 한다.
- **네이버 지도 링크는 남긴다.** 링크는 네이버를 부르지 않는다 — 앱이 주소를 만들어 휴대폰에 열어 달라고 할 뿐이다.
  - 편의시설: 앱이 `https://map.naver.com/p/search/<한국어 이름> <시군구>` 를 만든다(`NaverMapLink`). 그래서 POI 의 `name` 은
    언제나 한국어다(계약 「언어」).
  - 촬영지: 수집 CSV 의 `place_naver_url` 을 상세 `naverPlaceUrl` 로 내준다.

## 검토한 대안

| 선택지 | 채택하지 않은 이유 |
| --- | --- |
| 비공식 호출을 베타에도 유지 | 외부 배포다. 0011 이 스토어 제출 전에 대체하기로 했다. 막히면 화면이 비고, 이용 약관 위반 소지 |
| 네이버 공식 지역검색 API | 장소 id 를 주지 않아(0011 실측 4%) 사진·평점에 닿지 못한다. 결과를 화면에 쓰려면 약관을 따로 봐야 하고 호출 한도가 있다. 링크가 맞는지 확인하는 용도로도 다시 네이버를 부르게 된다 |
| 카드 창구와 코드를 지금 지우기 | 계약에서 창구를 빼는 것은 파괴적 변경이다. 앱이 이미 안 부르므로 급하지 않고, 버전 규칙을 먼저 정한다 |
| `poi_naver` 행을 두고 스위치만 끄기 | 카드 창구가 표에 있는 행은 계속 내준다 — 비공식 데이터가 응답으로 나간다 |

## 결과

**좋아지는 것**

- 외부 배포에서 비공식 호출과 그 데이터가 사라진다.
- 카드는 우리 데이터라 막힐 일이 없다.

**나빠지는 것**

- 카드에 영업시간이 없다. 사진·별점은 리뷰가 쌓일 때까지 거의 비어 있다.
- 편의시설의 네이버 링크는 검색 화면이다 — 같은 구에 같은 이름이 여럿이면 함께 뜨고, 네이버 이름과 다르면 못 찾을 수 있다.
  앱은 그것을 미리 알 수 없다(알려면 네이버를 불러야 한다). 버튼 문구로 기대를 맞추는 것(「검색」)은 앱의 몫으로 남긴다.
- MZ2AZ-327(네이버 이름 맞추기)은 할 필요가 없어진다.

## 검증

- 서버: `scenetrip.naver.enabled` 가 어디서도 true 가 아니고, `poi_naver` 행이 0, 카드 창구가 늘 「못 찾음」 이다.
- 앱: 카드 창구를 부르는 코드가 없다(`/pois/{id}/card`·`/pois/cards` 검색 0).
- 네이버 지도 링크가 전과 같이 열린다(앱 확인).
