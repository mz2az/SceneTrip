# ADR 0009: 기준 데이터(정예 4 작품 전량 CSV)를 저장소에 둔다

## 배경

로컬 스택은 팀원마다 자기 맥의 kind 클러스터에 Postgres 를 띄운다. 그 DB 는 빈 채로
태어나고, 채우는 수단은 `just seed`(CSV → `v6.sql` → 14 개 테이블)다. 공유 dev 서버는
아직 없다(`deploy.sh` 는 `local` 만 연결).

지금까지 저장소에는 표본 12 행(`v6-sample.csv`, 4 작품 × 장소 3 곳)만 두고, 전량
164 행은 팀 볼트(`mz2az` 저장소, `01_Raw/정승길/(1주차)data/result/`)에서 받게 했다
([계획 문서 §3](../../project/plans/scene-api-database.md), [ADR 0005](./0005-integration-test-dependencies-in-ci.md)
의 전제). 이유는 "데이터가 정제 전이라 정본은 볼트에" 였다.

2026-09-01 실측 — 팀원 세팅 안내(카톡판)대로 저장소만 클론해 `just stack-up` 을 하면
**작품 4 · 장소 10** 인 화면이 나온다. 볼트를 모르면 여기서 "데이터베이스가 다른 건가"
를 묻게 되고, 볼트를 알아도 경로가 사람마다 다르며(`~/mz2az` vs
`~/Library/CloudStorage/Dropbox/mz2az`) 파일명의 괄호 때문에 `just seed` 가 셸 오류를
냈다. 한편 데이터 자체는 MVP 범위가 **정예 4 작품으로 확정**되면서 164 행 · 150 KB 로
작아졌다 — "정제 전이라 크고 자주 바뀐다" 는 전제가 더는 성립하지 않는다.

## 결정

우리는 정예 4 작품 전량 CSV 를 `services/scene-api/seed/v6.csv` 로 저장소에 두고,
`just seed`(인자 없음)와 `just stack-up` 이 그것을 넣게 한다. 표본 12 행 파일은 지운다.
수집 산출물의 **정본은 여전히 볼트**이며 저장소의 파일은 그 스냅샷이다 — 볼트가 바뀌면
파일을 갈아 끼우고 같은 커밋에 근거를 적는다.

## 검토한 대안

| 선택지 | 채택하지 않은 이유 |
| --- | --- |
| 현행 유지 + 안내문에 "볼트 클론 → `just seed <경로>`" 추가 | 저장소 두 개를 클론해야 하고 경로가 사람마다 달라 안내가 길어진다. 실제로 이 단계가 빠진 안내문이 나갔다 |
| `stack-up` 이 볼트 경로를 환경변수로 받아 자동 적재 | 경로 문제만 풀고 "저장소만으로 재현" 은 여전히 안 된다. 볼트가 없는 CI 러너도 표본으로 돈다 |
| 표본을 유지하고 전량은 별도 파일로 추가 | 두 판을 유지하면 어느 쪽이 기준인지 흐려진다. 표본이 검증하려던 것(N:M, 별칭, movie 카테고리)은 전량에 다 들어 있다 |
| 공유 dev 서버를 세우고 앱이 그쪽을 보게 한다 | 맞는 방향이지만 인프라가 아직 없다. 생기면 로컬 시드는 선택이 되며 이 결정과 충돌하지 않는다 |

## 결과

**좋아지는 것**

- `git clone` + `just stack-up` 만으로 팀 전원이 같은 155 곳을 본다.
- CI 통합 테스트(ADR 0005)가 실제 규모의 데이터로 돈다.
- 카톡판 세팅 안내에서 데이터 단계가 사라진다(`stack-up` 한 줄).

**나빠지는 것 / 감수하는 비용**

- 저장소에 150 KB 데이터 파일이 하나 들어간다. 볼트와 이중으로 존재해 어긋날 수 있다 —
  갈아 끼울 때 커밋 메시지에 볼트 쪽 파일명·날짜를 적어 추적한다.
- 작품 수가 늘어(V7·V8) 파일이 수 MB 를 넘으면 이 결정을 다시 본다.

**후속 작업**

- 카톡판 세팅 안내의 "데이터 넣기" 절에서 seed 단계를 지우고 `just stack-up` 으로 통일.
- ADR 0005 의 "표본 12 행" 전제를 이 ADR 로 보정(`amended-by`).

## 검증

- 새 맥에서 `git clone` → `just stack-up` 직후 `curl localhost:8081/v1/places?limit=1` 의
  `total` 이 155 인가.
- 다음 데이터 판(V7)이 나올 때 이 파일을 갈아 끼우는 데 커밋 하나로 충분한가. 그렇지
  않다면(용량·빈도) 대안 4 로 옮긴다.
