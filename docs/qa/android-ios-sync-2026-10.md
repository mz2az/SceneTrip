홈의 작품에서 상세로 이동하면 촬영지 조회를 시작하지 않던 기존 오류도 수정했다.
홈·검색 목록·자동완성의 선택 ID가 바뀔 때 한 조회 흐름을 사용하며 이전 요청을 취소한다.
작품별 촬영지 API에 상한100보다 큰200을 보내400으로 거절되던 오류를 재현하고,
별도100개 단위 페이지 조회·중복 제거·실패 표시와 수동 재시도로 수정했다.
다른 작품/일반 장소로 이동할 때 이전 상세와 출처가 섞이지 않도록 정리했다.

## 검증 명령

- `just test //apps/scenetrip-android:unit_test`: Android 회귀 **87개**.
- `just android-run`: Bazel APK 빌드·설치·실행.
- `just android-photo-qa-server`, `just android-photo-qa-test`: 별도 설치 식별자의
  시험 APK에 실제 Android 터치 이벤트를 넣는다. 시험 서버는 PNG·JSON만 제공한다.
  결과의 FAIL도 레시피 실패로 전달한다. 제품의 계정·글·사진·코스는 읽거나 바꾸지 않는다.
- `just check`: 포맷·린트·119개 빌드 대상 및21개 테스트 대상 통과.
  PR CI와 job 로그는 병합 전에 별도로 확인한다.

비회원 상태의 공개 대구 가이드에서 코스 담기를 누르면 로그인 화면이 열리는 것을 확인했다.
검증 뒤 언어는 한국어, 화면 모드는 시스템, 글자 배율은1.0으로 복원한다.

실제 UI 시험과 합성 사진 시험을 구분한다. 공개 작품에 실제 씬 사진이 연결되어 있다는
근거로 시험 사진을 사용하지 않는다. 원본 캡처 픽셀에는 고정 글자가 정상적으로 남아 있었으며,
이미지 표시에서 보인 차이를 앱 렌더링 오류로 간주하지 않았다.

## 데이터·환경 보존

- 지역 가이드 JSON/상태와 이미 적재된 20개 글·32장 사진·20개 원본 코스는 재적재하지 않는다.
- MinIO 서명 URL의 원래 Host·경로·query를 유지한다. 로컬 API 빌드에서만 이미지 DNS가
  localhost 소켓을 10.0.2.2로 연결하며 API 인증 헤더를 이미지 서버에 전달하지 않는다.
- Android의 옛 후기 JSON 해시는 설치 전후 동일하다. 기존 기기에 로컬 후기 사진 디렉터리는 없었다.
  초기 보존 도구가 find의 오류 문자열을 사진 파일로 센 집계를 정정했다. 자동 공개·삭제하지 않는다.
- root 사용자 미커밋 파일22개는 해시 기준으로 보존한다. stage·stash·삭제하지 않는다.
- iOS Simulator·원본 백업·사용자 계정은 조작하지 않았다. 시험 코스161만 API로 정리했다.
- 실제 Google/Apple 인증·사진 리뷰·기기 GPS·유료 LLM/Kakao/TMAP·AWS 배포·공유 DB 마이그레이션은 실행하지 않았다.
