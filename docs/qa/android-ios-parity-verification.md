# Android 최신 iOS 기능 반영 검증

## 기준과 변경

2026-10-10, `MZ2AZ-148-android-ios-parity` 브랜치에서 현재 iOS 소스와 계약을 대조했다.
[작업 계획](../project/plans/android-ios-parity.md)의 리뷰·사진·POI 코스·재시도·한도·영어 문구를 반영했다.
계약·서버·iOS 소스·의존성 버전은 바꾸지 않았다.

## 자동 검증

| 명령 | 확인하는 범위 |
| --- | --- |
| `just test //apps/scenetrip-android:unit_test` | 리뷰·닉네임·사진 식별, POI 왕복, 편집 취소, 외부 지도, 연속 5분 도착, 요청별 재시도·한도·취소·늦은 응답 |
| `just test //tools/scripts:android_translations_unit_test` | iOS 형식 지정자·따옴표·줄바꿈·달러·중복 문구·빈 입력 |
| `just android-run` | 지도 설정을 주입한 APK 빌드·설치·실행 |
| `just check` | 전체 포맷·린트·빌드·빠른 단위 레인 |

최종 결과: Android 테스트 **22개**, 번역 변환 시험 **4개** 통과. `just check`의
전체 빌드와 빠른 레인 **19개 타깃**이 통과했다. 지도 설정을 주입한 APK도 빌드·설치·실행했다.

공통 HTTP 시험은 실제 OkHttp 인터셉터를 사용하고 시간·응답만 주입한다. 소켓·실서버·실제 대기 없이
삭제 응답 유실 뒤 404를 완료로 처리하는 경우, 읽기·안전한 PUT의 일시적 오류, 도착 여부가 불명확한
POST의 재전송 금지, 계정 전환 뒤 이전 한도 응답 무시를 검증한다.
합성 204 응답에 몸통이 없어 OkHttp가 거절하던 오류는 빈 몸통을 넣어 수정했다.
취소는 화면 오류로 바꾸지 않고 전파하므로 이전 검색이 새 결과를 덮지 않는다.

## 에뮬레이터 검증

Android Studio 없이 기존 Android 에뮬레이터를 `just android-emulator`로 유지하고
`just android-run`·`just android-device`·`just android-ui`·화면 캡처로 확인했다.
로컬 서버의 기존 데이터를 읽었으며 리뷰·코스를 저장하거나 유료 가이드를 호출하지 않았다.

- 홈과 검색에서 실제 작품·장소 데이터, 한국어·영어 전환과 프로필 진입을 확인했다.
- 월연정 상세에서 공식 사진의 전체 비율, 사진첩·크게 보기와 촬영 장면을 확인했다.
- 평점 요약에서 리뷰 목록을 열고 최신순·높은 별점순·낮은 별점순·빈 상태를 확인했다.
- 비회원의 리뷰 작성·프로필 로그인 입구는 Google 로그인 시트를 연다.
- 평점 분포는 진행률 위젯 대신 가운데 정렬된 막대를 사용하며 빈 분포는 빈 막대로 표시한다.
- 시트를 끌어 닫을 때 편집기가 버리기 확인을 띄우면 계속 쓰기 후에도 시트를 다시 표시한다.
- 직접 코스 만들기에서 기간·날짜·빈 초안 진입 후 제목을 바꿨다. Android 뒤로가기와
  시트 끌어내리기 모두 버리기 확인을 띄우고, 계속 편집을 선택하면 변경한 제목·화면이 유지됐다.

## 확인 범위의 한계

Google 실계정 인증, 로그인 후 리뷰·사진 저장·삭제, 실제 기기의 사진 회전·메타데이터 제거,
장시간 GPS 주행·백그라운드 전환과 유료 가이드·길찾기 한도 도달은 이번 수동 검증에서 실행하지 않았다.
이 경로의 규칙·계약·오류 분기는 단위 시험과 APK 컴파일로 확인했으며 실제 기기 검증이 추가로 필요하다.
화면 전반의 자동 UI 시험이나 커버리지 수치 측정은 수행하지 않았다.

## 되돌리기

이 브랜치의 Android 기능 반영 커밋을 되돌리면 이전 앱 동작으로 돌아간다. 서버 계약·DB 변경이
없어 데이터 마이그레이션은 필요 없다. 기기 앱 데이터를 지우거나 계정을 삭제할 필요도 없다.
