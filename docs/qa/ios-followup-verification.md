# iOS 이관 후속 검증 — MZ2AZ-387

## 범위와 환경

2026-10-10, main `1963914`에서 분리한 작업 폴더로 iOS만 검증했다.
iPhone 17 / iOS 26.5 시뮬레이터, 기존 로그인·코스·리뷰를 사용했다.
가이드·길찾기 유료 호출은 시험 응답으로 막았다. 리뷰·코스의 저장·삭제는 누르지 않았다.

## 확인한 결과

| 항목 | 결과 |
| --- | --- |
| 큰 글자 안내 | `accessibility-extra-large`에서 해태 말풍선이 한도 안내와 지도 앱 넘기기 단추를 가리는 현상 재현 |
| 배치 회귀 시험 | 기존 배치를 반영한 시험에서 `floating != tripHeader`로 실패 확인 후 수정 |
| 업로드 429 | `RATE_LIMITED`와 `Retry-After: 61` 시험 응답. 이유·재시도 표시, 저장 차단, 실패 사진 제거 후 저장 가능 확인 |
| 업로드 401 | `SIGN_IN_REQUIRED` 시험 응답. 다시 로그인하라는 문구·저장 차단 확인. 기존 로그인 토큰을 폐기하는 오류는 주입하지 않음 |
| 저장소 PUT | URLProtocol로 예약 → PUT 경계 전체를 검증. 403은 저장소 실패, 연결 실패는 네트워크 실패, 자동 PUT 재전송 없음 |
| 인증 헤더 | 예약 POST에 넣은 시험용 Authorization이 저장소 PUT으로 전달되지 않음 |
| 안내 입구 | 한국어 큰 글자의 medium/expanded, 영어 일반/큰 글자에서 제목 옆 46pt 버튼이 안내를 가리지 않음. 서랍 열기·닫기 확인 |
| 장소 카드 | 카드가 안내 제목을 덮을 때 카드 위 떠 있는 입구로 전환. 카드·서랍을 닫으면 원래 입구로 돌아옴 |
| 영어 지도 앱 단추 | 큰 글자에서 44pt 틀 밖으로 그리던 현상 수정. 자연 높이 91.3pt, 펼친 시트의 안내/단추/복귀 문구 사이 약 8pt 간격 확인 |
| 회귀 시험 범위 | 기존 카드 회피 시험에 입구 정책 4개·업로드 전송 4개 추가. 전체 게이트 결과는 아래 기록 |

사진 실패 확인은 화홍마트 리뷰 편집 사본에서 했다. 429에서 별점을 잠깐 바꿔 실패 사진
제거 후 저장 가능 여부를 확인하고 버렸다. 기존 리뷰 내용·사진은 저장하지 않았다.
PUT 실패는 가짜 저장소 응답을 사용한 단위 시험이며 실제 S3 장애를 만든 결과는 아니다.

## 보존과 한계

검증 전후 리뷰 4건, 코스 2건, 코스 항목 7건, 장소 찜 3건, 작품 찜 3건,
촬영지/편의시설 연결 82건의 전체 행 요약이 같다. 저장된 해태 위치 `dx=0`, `dy=-132`도 같다.
시험 응답을 지우고 `demoDrive=0`, 한국어, 라이트, 원래 글자 크기 `large`로 홈을 다시 열었다.

두 지도 앱이 설치된 실제 기기, 실제 저장소 장애, 로그인 토큰을 폐기하는 오류는 검증하지 않았다.
장소 카드의 실제 화면 확인은 접힌 시트에서 했다. 다른 시트 높이의 카드 배치는 정책 시험으로 확인했다.
영어 큰 글자의 상단 취소/저장 줄바꿈과 medium 시트에서 복귀 문구가 하단 단추에 가리는
문제는 [MZ2AZ-388](https://mz2az.atlassian.net/browse/MZ2AZ-388)에 남겼다.
387은 코스 편집 화면 전체의 접근성을 완료했다는 의미가 아니다.

## 검사

독립 코드 검토에서 막는 문제는 없었다. `just check`가 통과했고, 빠른 시험 대상 17개가
모두 성공했다. iOS는 578개 시험이 실패 없이 통과했다(입구 정책 4개·업로드 전송 4개 추가).
PR CI 결과는 해당 PR의 검사와 통합 결과보고서에서 확인한다.
