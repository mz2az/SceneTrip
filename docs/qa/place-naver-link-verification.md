# 촬영지 네이버 링크 검사 — MZ2AZ-383

2026-10-09, iOS 시뮬레이터와 로컬 API에서 확인했다.

## 수정과 시험

촬영지 상세와 지도 카드도 편의시설과 같은 `NaverMapLink.place` 검사를 거친다.
HTTPS·네이버 호스트·포트 및 사용자정보 없는 주소만 표시하고, 없거나 잘못된 값이면 버튼을 숨긴다.
촬영지에 연결된 편의시설 카드도 촬영지 상세의 링크를 검사한다.

- 수정 전 카드 회귀 시험에서 외부·위장 호스트, 다른 스킴, 공백 등 11개 검사가 실패했다.
- 수정 후 `just test //apps/scenetrip-ios:unit_test`: 565개 시험, 실패 0개.
- `just check`: 포맷·린트·전체 빌드·빠른 시험 15개 타깃 통과.
- 데이터 삭제 없이 새 앱을 설치해 화홍마트 촬영지 상세의 정상 네이버 버튼 표시를 확인했다.

잘못된 주소의 버튼 숨김은 순수 카드 회귀 시험과 상세 화면 배선 검토로 확인했다.
시뮬레이터의 실제 자료에는 정상 주소만 있어 잘못된 주소를 화면에 주입하지 않았다.
외부 브라우저 이동과 실제 기기는 이번 확인 범위 밖이다.

## 함께 확인한 사진 기능

기존 화홍마트 리뷰에서 사진을 골라 서버 URL 발급 → MinIO PUT을 확인했다.
완료 뒤 저장 버튼이 활성화됐고, 내려받은 JPEG는 24,627바이트로 정상 표시됐다.
리뷰 저장은 누르지 않고 취소·버리기로 닫았다. 이번 임시 객체와 업로드 기록 한 개는 정리했다.
서버가 새 업로드를 기록할 때 하루 지난 임시 기록 20개를 자동으로 지웠다(`UploadStore.record`).
기존 리뷰·코스·항목·찜·장소 연결의 전체 행 해시는 확인 전후 같았다.

커뮤니티 사진 선택·미리보기는 됐다. 여행후기는 기기 저장이며 서버 연결은 MZ2AZ-352가 남아 있다.
