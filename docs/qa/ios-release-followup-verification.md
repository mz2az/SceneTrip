## 수정과 자동 검증

각 결함은 지연 응답과 세션 전환을 조작하는 회귀 시험을 먼저 추가했다.
기존 동작에서는 실패하고 수정 뒤 통과한 로그를 로컬 검증 폴더에 보관한다.

| 조건 | 수정 후 결과 |
| --- | --- |
| A의 refresh 성공 뒤 B 로그인 | A 토큰이 B 토큰을 덮지 않음 |
| A의 늦은 refresh 401 뒤 B 로그인 | B를 로그아웃시키지 않음 |
| A 갱신 대기 중 B 갱신 | 다른 세션의 요청끼리 대기하거나 결과를 공유하지 않음 |
| 닉네임 저장 뒤 옛 GET /me 도착 | 저장한 새 닉네임 유지 |
| A 리뷰 초안 뒤 B 로그인 | 이전 초안의 저장·삭제 요청 차단, 업로드 취소 |
| 늦은 리뷰 조회·저장·옛 정렬 응답 | 새 계정/정렬 상태에 적용하지 않음 |
| 커뮤니티 사진 실패 후 상세 재조회 | 사진 주소·bodyBlocks·출처·AI 표시를 같은 응답으로 교체 |
| 같은 화면의 여러 사진 실패 | 재조회 한 번 공유, 자동 30초 제한·수동 재시도 가능 |
| 기기의 옛 후기 사진 | 서버 재발급 요청 없이 기존 파일 사용 |
| 이미 읽은 리뷰 40개 재발급 | 둘째 쪽의 21번째 이후 주소까지 함께 갱신 |
| 다음 쪽 대기 중 새 리뷰 삽입·재발급 | 옛 offset 응답 폐기, 새 목록에 맞춰 이어 받음 |
| 사진 갱신 중 다음 쪽 로드 | 순서가 확정될 때까지 로드 억제, 갱신 실패 뒤도 잠금 해제 |
| 계정 전환·다른 글 표시 뒤 늦은 사진 응답 | 이전 응답 폐기 |
| 사진 키 배열 변경 | 확대 화면의 선택 키 유지 또는 유효한 범위로 조정 |
| 실제 시험 번들 리소스 | UserDefaults CA92.1 매니페스트·한국어/영어 위치 문구 포함 |

검증 명령:

```bash
just test //apps/scenetrip-ios:unit_test
just check
```

iOS 전체 **716개** 시험 통과(기준 692개에서 의미 있는 회귀 24개 추가).
`just check`의 형식·정적 검사·전체 빌드·**22개 시험 대상** 통과.
별도 검토자는 코드만 읽었다. 갱신과 다음 쪽의 경합을 추가로 찾아 수정한 뒤,
해당 diff 범위에서 추가 차단 결함을 찾지 못했다고 보고했다.

## 실제 화면 확인

사용자 iPhone 17과 분리된 SceneTrip Apple QA 기기(iPhone SE 3 크기, iOS 26.5)에
`just ios-run`으로 데이터를 유지하며 설치했다.

| 화면 | 실제 관찰 | 검증 범위 |
| --- | --- | --- |
| 홈·인기 작품 | 고정 칸의 포스터와 첫 작품 순서 표시 | 재실행·AX·기기 캡처로 표시 확인 |
| 커뮤니티 목록 | 기존 지역 추천 글과 AI 변환 대표 사진 표시 | 실제 로컬 API 조회 뒤 표시 확인 |
| 닉네임 영어·라이트/다크 | 설명·작성자 미리보기·입력·저장/건너뛰기 표시 | 기존 previewNickname 옵션의 비회원 미리보기 |
| 닉네임 한국어·접근성 큰 글자 | 큰 시트·본문·하단 저장/건너뛰기 영역 표시 | accessibility-extra-large, 정상 크기 복원 |

화면 입력 도구는 tap/gesture 성공을 반환했으나 AX와 캡처에서 이동이 확인되지 않았다.
별도 QA helper를 재연결해도 같았고, macOS 화면 잠금 플래그가 `Yes`였다.
접근성 권한은 허용으로 조회됐지만 Device Hub AX 조회는 실패했다.
이 입력을 홈 스와이프·포스터 탭·글 상세/사진 확대의 성공으로 집계하지 않는다.
기존 시뮬레이터·원래 계정에 인증 우회 기능을 추가하지 않았다.
