# 기기 후기 보존과 지역 가이드 검증 (MZ2AZ-423)

2026-10-13. [계획](../project/plans/community-regional-guides.md),
[자료 인덱스](../product/community-guides/README.md),
[로컬 적재 절차](../ops/community-guides-local.md)를 따른다.

## 보존

기존 기기 글 `How`, `낙산공원 성곽길, 케데헌 그 장면 그대로였어요`는
기기 저장 자료에 원문·첨부 코스와 함께 남아 있었다. 사진은 각각 1장·4장이다.
원본 JSON과 사진 5장을 저장소 밖에 따로 백업했고 해시를 기록했다. 원래 글을
서버에 게시하거나 계정에 귀속시키지 않는다. 기존 코스·찜·리뷰는 정리 대상이 아니다.

## 자료 검사

- 가이드 20개 모두 지역 경계·지점 3~4개·사진 출처·길이 검사 통과. 범위는 최대
  직선거리 18.1km이며 실제 도로 거리나 길찾기 결과는 아니다.
- 사진 첨부 32장의 공급자 주소·제1유형 표기·장소 좌표·이미지 크기를 확인했다.
  150×100 두 장과 좌표가 불확실한 김녕 사진은 제외했다. 대표 사진을 직접 보며
  실제 피사체를 확인했다. 참고 풍경은 본문에서 구분한다.
- 독립 검토로 코스 응답을 새 기준으로 삼던 문제·사진 리다이렉트 선검사·중단된
  캐시·다른 작품의 장소 검사 생략·확정 4xx 후 재개·옛 글이 있어도 빈 목록 안내가
  나오던 문제를 찾아 보완했다. 외부 서비스 없는 회귀 시험을 추가했다.

## 실행 결과

| 확인한 것 | 결과 |
| --- | --- |
| 로컬 공개 가이드 | 글 20개(27–46), 원본 코스 20개(140–159) 생성·조회 통과 |
| 사진 첨부 | 32장 모두 공개 사진 바이트와 내려받은 원본 SHA-256 일치 |
| 코스 사본 | 요청한 1일차·장소 종류/ID·순서·체류 시간을 20개 모두 대조 |
| 다른 회원의 담기 | 별도 시험 회원으로 새 코스 ID·`origin: market`·같은 장소/시간 확인, 시험 회원·코스 정리 |
| 원래 DB 데이터 | 적재 직후 기존 12개 테이블의 원래 행 수·해시 일치. 원래 코스 2개/항목 7개·리뷰 4개/사진 13개·찜 보존 |
| iOS 공개 화면 | SE 3세대에서 목록 대표 사진·대구 글 전문/사진/출처·1일 3곳 코스·비회원 담기의 로그인 안내 확인 |
| iOS 기기 글 | 사용하던 iPhone 17에 덮어 설치. 두 글이 기기 보관 절에 표시되고 낙산 글의 원문·원래 사진·첨부 코스 확인 |
| 단위·전체 게이트 | 가이드 회귀 20개, iOS 682개 통과. `just check`의 21개 검사 대상 모두 통과 |
| 독립 검토 | 마지막 보완 뒤 추가 차단 결함 없음. 읽기 전용 정적 검토이며 실제 실행 결과와 구분 |

사진 5장의 존재·원본 해시는 모두 대조했지만 옛 글의 사진 페이지를 전부 넘기는
조작은 완료하지 못했다. 공개 20개는 API에서 모두 검증했고 iOS 상세는 대표 글로
확인했다. 앱 전체 E2E나 실제 OAuth 로그인 시험의 완료를 뜻하지 않는다.

## 실행 중 확인한 문제

로컬 scene-api 컨테이너가 512Mi 메모리 한도로 `OOMKilled`되어 사전 조회 연결이
한 번 끊겼다. 재시작 뒤 정상 응답했고 같은 상태 파일로 재개했다. 첫 코스 생성은
준비 명령의 잘못된 `origin: manual` 때문에 400으로 거절됐다. 실제 생성된 코스가
없음을 확인하고 계약의 `self`로 수정했다. 확정 거절과 응답 유실의 재개 규칙도 구분했다.

전체 검사 중 Maven 의존성 다운로드의 `Premature EOF`가 있었고 재시도 뒤 통과했다.
Orca의 터치는 기본 홈 아이콘에도 전달되지 않아 Device Hub의 접근성 버튼 호출로
실제 화면을 확인했다. 화면 캡처 실패와 동작 실행 여부는 별도로 확인했다.

## 남은 연계

Jira MZ2AZ-376에 김녕 TourAPI POI/사진 좌표 불일치를 근거와 함께 남겼다.
MZ2AZ-425는 MZ2AZ-424의 계약 필드 추가가 선행되어야 한다. 현재 `GuidePlanStop`에는
`placeId`만 있고 `poiId`·`customPinId`가 없어 프론트 작업은 계약을 먼저 기다린다.

## 범위

이번 적재는 로컬 kind와 MinIO이다. 운영·AWS·다른 DB로 자동 반영하지 않는다.
유료 길찾기나 실제 LLM 호출은 하지 않는다. Apple 서버 키·스토어 서명·실기기
로그인·GPS 길찾기와 Android 동등성의 남은 조건은 기존 티켓을 따른다.
