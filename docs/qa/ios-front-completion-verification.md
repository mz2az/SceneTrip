# iOS 프론트 후속 검증 — 2026-10-13

[MZ2AZ-148](https://mz2az.atlassian.net/browse/MZ2AZ-148) 계획의 iOS 변경이다.
사용자 기기와 다른 Android 세션을 보존하기 위해 별도 iPhone SE 시험 기기에서
확인했다. 다음 표는 실제 화면 확인과 코드·단위 검사를 구분한다.

## 결과와 한계

### 2026-10-15 길안내 보완 (MZ2AZ-117·250)

숫자 영문 호선을 지하철로 분류하고 중복 노선·한국어 차종 제목을 제거한다.
길안내 목적지·언어 안내는 줄바꿈하고, 시간·요약은 좁은 화면에서 세로로 배치한다.
회귀 검사는 영문 호선·버스 우선 분류와 한·영 요약의 240/600pt 너비,
기본 글자/접근성 3단계의 실제 SwiftUI 크기 계산을 다룬다.
이는 전체 화면의 육안 검증이나 실제 도보·환승 경로의 번역 완료를 뜻하지 않는다.
117의 전체 주요 화면·실기기 검증 및 250의 버스 차종·서버 안내문 검증은 남는다.

## 사진·DB 대조

- 별도 시험 회원·설치·장소·작품으로 리뷰 사진을 업로드했다. DB 메타데이터와
  로컬 MinIO 객체에서 내려받은 바이트가 원본 1,449바이트와 일치했다.
- 세 작품은 정상 씬 사진·404 사진·씬 사진 없음으로 나눴다. 마지막 작품에는
  포스터가 있어도 씬 카드가 비워지는 것을 실제 화면에서 확인했다.
- 시험 자료는 검증 후 식별자와 접두사를 확인해 정리한다. 기존 사용자 글·코스·
  사진·로그인 데이터를 시험용으로 변경하지 않는다.
- 최신 후보 CSV 538행에는 `scene_image_url`이 없었다. DB의 비어 있지 않은
  33개 주소도 현재 공개 작품과 장소에 함께 연결되지 않았다. 사진 뷰어 확인은
  합성 시험 사진으로 했으며 실제 씬 사진 준비는 MZ2AZ-349로 남는다.
- 공식 main과 로컬 Flyway 이력을 맞추기 전에 DB를 백업했다. 조정 전후 기존
  12개 표의 행 대조가 같았다. AWS 배포와 공유 DB는 변경하지 않았다.

## 출시와 Apple 로그인

Apple 앱 코드는 PR #235로 main에 있다. 로컬 서버의 Apple 개인 키와 토큰 암호화
키가 없어 `/auth/apple`은 501을 반환한다. 시뮬레이터 Apple 계정 로그인은 서버
개인 키를 공급하지 않는다. 키·개발자 팀 서명·실제 가입/재로그인/탈퇴 검증은
MZ2AZ-415·416의 남은 조건이다. 광고 동의 정책과 유료 LLM·길찾기를 시험 호출하지
않는 조건은 유지했다.
