# Android 포스터·홈 선반·닉네임 검증 (MZ2AZ-431)

iOS PR260의 main `8378ade`에서 분기한 Android 전용 브랜치로 진행했다.
[계획](../project/plans/android-home-profile-polish.md)을 따르며 iOS·서버·계약을 수정하지 않는다.
포스터Fit 결정을 최신431의 고정 칸 중심Crop으로 바꾼다. 장소·실제 씬 사진과 제작사 링크 규칙은 유지한다.

## 자동 검사

- Android 단위99개 및 `just check`119개 빌드·21개 테스트 대상 통과.
- 닉네임 정하기의 같은 자동 이름은 서버 없이 시작하며, 변경 화면의 같은 이름은 저장할 수 없다.
  NFC·공백·글자 수·최대 길이·예약 이름·실패 뒤 편집을 확인한다.
- 진행 중 중복 저장 차단, 시작 전/응답 중 계정epoch 변경, 늦은 성공/실패, 예외·취소를 검사한다.
  기존AccountReply의 다른 응답 회원ID·이전계정 응답 검사도 유지한다.
- 기존 검색API 취소 시험이 CancellationException을 반환해 JUnit에서 실행되지 않던 경고를 확인했다.
  `runBlocking<Unit>`로 시험 반환형을 고쳐 실제 취소 전파 회귀를 실행한다.

## 별도 QA APK의 실제 터치

`just android-nickname-qa`는 `com.mz2az.scenetrip.qa` 설치본의 모의 이름/응답만 사용한다.
제품 AuthStore·OAuth·API 쓰기를 시작하지 않는다. 실제 회원의 닉네임 저장 증거로 간주하지 않는다.

화면이 바뀌기 전의 접근성 좌표는 성공 근거로 쓰지 않았다. 저장 버튼이 키보드 위로 이동한 중간 좌표를
눌렀던 한 시도는 제외하고, 진행 상태의 실제 화면과 터치 전후 유지 결과를 확인했다.
시험 뒤 QA 설치본을 삭제하고 제품의 글자 배율1.0을 복원했다.

## 제품 홈·포스터

제품 APK 설치 뒤 공개 API로 홈·작품 진입·가로 선반 이동을 확인했다.
기생충·오징어 게임·케이팝 데몬 헌터스에서 가로 이동 후 올드보이·사랑의 불시착·지금 우리 학교는을
확인하고 반대로 이동해 원래 위치로 돌아왔다. 기생충 상세의 전체 너비176dp 포스터·제작사 화살표·출연·두 촬영지를 확인했다.
포스터 원본에 포함된 흰 가장자리는 원본 그림 일부이며 별도로 자르거나 이미지를 편집하지 않았다.
제작사 링크의 최종 외부 브라우저 이동을 이번 검사에서 확인했다는 뜻은 아니다.

`just android-home-qa-test`를 수정 전 실행했을 때 전체 보기 뒤 이전 작품 상세가 남아 실패했다.
전체 보기의 명시적 목록 진입을 추가하고, 바 위로 나온 홈 원의 실제 터치 영역을 전체 화면 부모로 옮겼다.
원 위치는 기존 레이아웃의 측정값을 사용해 글자 배율에 따른 배치도 따른다.
수정 뒤 같은 시험에서 홈 원 위쪽20% 지점 터치·상세 복귀·전체 보기의 인기 작품 목록·다시 홈 복귀를 통과했다.
여러 실제 회원 코스·팀원 기기에서의 손가락 문제는 별도이며, 재현하지 않은 원인을 해결했다고 쓰지 않는다.

## 보존·외부 조건

사용자 계정·원래 글/사진/코스·root 미커밋 변경과 iOS Simulator는 조작하지 않는다.
공용 API 재기동 완료 통지 뒤 공개 읽기만 재개하며 DB seed/reset·유료 가이드/길찾기·AWS 작업은 수행하지 않는다.
428 bodyBlocks와 AI 사진은 계약 main 인계 뒤 별도로 반영한다.

되돌리기는 Android PR revert로 충분하다. 계약·DB 마이그레이션이나 기기 초기화는 필요 없다.
