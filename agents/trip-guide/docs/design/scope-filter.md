## 설계

1. **호출 전 판정(`src/scope.py`)** — 무관한 갈래의 낱말(주가·주식·비트코인·코드 짜·시스템 프롬프트·지시 무시 등)이 있고,
   여행 낱말(촬영지·여행·일정·코스·근처·카페·날씨 등)이 **하나도 없을 때만** 모델 없이 거절한다. 낱말 목록과
   거절 문구(한·영·일)는 `config/scope.json`. 여행 낱말이 섞이면(혼합 C1) 모델에게 넘긴다 — 여행 부분을 버리지 않는다.
2. **지시문(`prompts/system.txt`)** — 날씨는 받되 실시간 값을 지어내지 않는다, 섞인 질문은 여행 부분만 처리하고
   나머지는 한 줄로 못 한다고 한다.
3. 거절 문구는 짧게, 할 수 있는 일을 사람의 말로 한 줄 덧붙인다(도구 이름 없이).
