# 여행 범위 필터 — 무관한 질문은 거절한다 (MZ2AZ-398)

> 작성 2026-10-15 · 담당 김태환

챗봇이 일반 ChatGPT 처럼 쓰이지 않게, 여행과 관련된 질문만 받고 나머지는 짧게 거절한다.

## 기능 테스트 목록

**구현 전에 세운 목록이다.** 구현 뒤 같은 물음을 실제 모델로 다시 물어 결과를 적는다(아래 「결과」).
결정적 시험(`tests/test_scope.py`)은 목록의 모든 물음이 모델에게 가는지(F1)를 확인한다.

| # | 갈래 | 물음 | 기대 |
| --- | --- | --- | --- |
| A1 | 허용 — 날씨·일정 | 내일 제주 비 오면 일정 어떻게 바꿀까? | 거절하지 않는다. 실시간 날씨를 지어내지 않고, 비 오는 날의 대안(실내 촬영지·일정 조정)으로 돕는다 |

## 설계

1. **판단은 모델이 한다.** 모든 물음을 모델에게 보내고, 범위 밖이면 모델이 지시문(`prompts/system.txt`)대로 한 줄로 거절한다.
2. **지시문** — 날씨는 받되 실시간 값을 지어내지 않는다, 섞인 질문은 여행 부분을 도구로 찾아 답하고 나머지는 한 줄로 못 한다고 한다.
3. 거절은 짧게, 할 수 있는 일을 사람의 말로 한 줄 덧붙인다(도구 이름 없이).

## 바뀐 것 (2026-10-15)

처음 판(PR #292)은 「무관 낱말이 있고 여행 낱말이 없으면 모델을 부르지 않고 거절」 하는 단어 목록 사전 차단(`src/scope.py`)을 넣었다.
사용자 결정으로 뺐다 — 단어로 코드가 가로채지 않고 모든 물음을 모델에게 보낸다. 비용은 거절 한 번에 모델 한 번(실측 1.4~2초)이다.
지시문 보강(섞인 질문·날씨)은 그대로 둔다.
