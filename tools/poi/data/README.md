# tools/poi/data — 이름 영어화의 사전

계획: [poi-i18n-image.md](../../../docs/project/plans/poi-i18n-image.md) §12.

| 파일 | 내용 | 출처 |
| --- | --- | --- |
| `hansik800.tsv` | 한식 메뉴 800 개의 한국어·로마자·영어. **지금은 쓰지 않는다** — 메뉴명 번역을 뺐다(계획 §12-6). 나중에 AI 로 이름을 다듬을 때 용어집으로 쓴다 | 한식진흥원 「한식메뉴 외국어표기 길라잡이 800선」(공공데이터포털 15129784, 2023-06-01 판). **이용허락범위 제한 없음, 무료.** 원본 XLSX 에서 번호·갈래·요리명·로마자·영어 다섯 칸만 뽑았다 |
| `generic.tsv` | 흔한 낱말(식당·카페·치킨…)의 영어와, 번역해도 되는 가게 분류 | 직접 작성 |
| `brands.tsv` | 체인 브랜드의 공식 영어 이름 — **초안, 사람 검수 필요** | 직접 작성. 상가정보 2026-06 판에서 지점이 많은 이름부터 |

영어 이름은 브랜드 사전과 흔한 낱말로 **확실한 것만** 만든다. 사전에 없으면 영어 이름은 비고 로마자 읽기만 붙는다.
